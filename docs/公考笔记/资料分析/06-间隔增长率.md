# 第六章 间隔增长率

> 💡 **核心要点**：间隔增长率 r = r₁ + r₂ + r₁×r₂，当r₁、r₂均<10%时可忽略r₁r₂项，间隔倍数=间隔增长率+1。

---

## 📖 知识点详解

### 6.1 间隔增长率公式

#### 🔹 示例1：基础计算（基础）

> **题目**：2014年1-2月西藏出口额增长7.2倍，2014年比2012年同期多少倍？
> A. 0.2　B. 0.6　C. 1.7　D. 8.2
>
> 📊 **解题流程图**：
> ```
> 2014年增长率 = 720%
> 2013年增长率 = -79.7%
> 
> r间 = r₁ + r₂ + r₁×r₂
>     = 720% + (-79.7%) + 7.2×(-79.7%)
>     = 640.3% - 573.84%
>     = 66.46%
> 
> 间隔倍数 = 1 + 66.46% = 1.66 ≈ 1.7
> ```
>
> ✅ **解析**：代入公式，r₁r₂=7.2×(-80%)=-576%，得66%增长，1.66倍，选C。

#### 🔹 示例2：忽略乘积项（进阶）

> **题目**：2019年增长24%，较2019年增长16%，求2020年比2019年？
>
> 📊 **解题流程图**：
> ```
> 已知：r₁=24%（2021比2020），r间=16%（2021比2019）
> 求：r₂（2020比2019）
> 
> r间 = r₁ + r₂ + r₁×r₂
> 16% = 24% + r₂ + 24%×r₂
> -8% = 1.24×r₂
> r₂ = -6.45%
> → 下降了不到10%
> ```
>
> ✅ **解析**：用逆向公式，r₂=(16%-24%)/(1+24%)=-6.45%，选D。

#### 🔹 示例3：多年间隔估算（挑战）

> **题目**：2015年服务业投资额31.19万亿，2012-2015年均增长15.9%，则2015年比2012年增长约？
> A. 16%　B. 56%　C. 48%　D. 32%
>
> 📊 **解题流程图**：
> ```
> 估算：16%×3 = 48%
> 实际值 > 48%（因为有r₁r₂相乘）
> 
> 精算：
> 第1年：16%
> 第2年：16%+16%+16%×16% = 34.56%
> 第3年：34.56%+16%+34.56%×16%
>      = 50.56% + 5.53%
>      = 56.09% ≈ 56%
> ```
>
> ✅ **解析**：年均16%，3年累计>48%，精算约56%，选B。

## ⚡ 速算技巧总结

| 技巧 | 适用场景 |
|------|---------|
| 忽略乘积 | r₁,r₂均<10%时，r₁r₂<1% |
| 加法估算 | 多年间隔，先加后微调 |
| 逆向公式 | 已知r₁和r间，求r₂ |

---

## ⚠️ 易错点提醒

- ❌ **r₁r₂符号**：一正一负时，r₁r₂为负
- ❌ **间隔倍数**：要加1，不是直接用r
- ❌ **逆向运用**：分母是(1+r₁)，不是r₁
