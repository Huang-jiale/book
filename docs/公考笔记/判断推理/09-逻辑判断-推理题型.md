# 逻辑判断-推理题型

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第115-128页

---

## 一、推理类基本题型概述

推理类基本题型考查的核心是基于逻辑基本原理的七种题型：

| 题型 | 说明 |
|------|------|
| **翻译推理** | 将文字语言转化为箭头语言，利用逆否命题解题 |
| **真假推理** | 找到矛盾关系或反对关系，判断真假 |
| **分析推理** | 根据条件进行逻辑分析，推出结论 |
| **归纳推理** | 从个别到一般的推理 |
| **解释推理** | 解释题干中的现象或矛盾 |
| **数学推理** | 运用数学知识进行逻辑推理 |
| **相似推理** | 找出与题干逻辑结构相似的选项 |

---

## 二、翻译推理

### 1. 解题步骤

1. 将文字语言转化为箭头语言
2. 找到充分条件和必要条件
3. 画出箭头（充分条件在前，必要条件在后）
4. 充分利用逆否命题解题

### 2. 常用等价关系

| 原命题 | 等价命题 |
|--------|----------|
| A→B | -B→-A（逆否命题） |
| A→B | -A或B |
| 并非（A且B） | -A或-B |
| 并非（A或B） | -A且-B |

### 3. 例题解析

**例题1（2016国考）**

> 某大型晚会的导演组在对节目进行终审时有六个节目尚未确定是否通过，这六个节目分别是歌曲A、歌曲B、相声C、相声D、舞蹈E和魔术F。综合考虑各种因素，导演组确定了如下方案：
> （1）歌曲A和歌曲B至少要上个；
> （2）如果相声C不能通过或相声D不能通过，则歌曲A也不能通过；
> （3）如果相声C不能通过，那么魔术F也不能通过；
> （4）只有舞蹈E通过，歌曲B才能通过。
> 导演组最终确定舞蹈E不能通过。

**解析**：
- （1）A或B
- （2）-C或-D→-A，等价于：A→C且D
- （3）-C→-F，等价于：F→C
- （4）B→E

根据条件（4），-E→-B；根据条件（1），-B→A；根据条件（2），A→C且D。

得到：-E→-B→A→C且D，可以确定A-E五个节目的情况，但是不知道节目F的情况。

**例题2（2018联考）**

> 一个人如果是智者，那么他一定是一位谦虚的人；而一个人只有认识到自己的不足，他才会谦虚。但是，如果一个人听不进别人的意见，那么他就不会认识到自己的不足。

**解析**：翻译得到：智者→谦虚→认识不足→听得进意见。B选项是逆否命题，正确。

## 三、真假推理

### 1. 解题步骤

1. 找到矛盾关系或反对关系
2. 利用矛盾关系（必有一真一假）或反对关系（必有一假/必有一真）判断
3. 推出其他命题的真假

### 2. 矛盾关系与反对关系

| 关系类型 | 形式 | 性质 |
|----------|------|------|
| **矛盾关系** | A与非A | 必有一真一假 |
| **上反对关系** | 所有A都是B 与 所有A都不是B | 必有一假，可以同假 |
| **下反对关系** | 有的A是B 与 有的A不是B | 必有一真，可以同真 |

### 3. 例题解析

**例题（2018广州）**

> 下面是某冬日我国北方某些城市的天气情况：
> （1）有些城市有降雪；
> （2）有些城市没有降雪；
> （3）北京和邯郸没有降雪。
> 如果三个断定中只有一个为真，那么以下选项中哪个断定一定为真？

**解析**：①②两个"有的"必有一真，又因为只有一个真的，所以③错①对②错，那么所有城市都下雪。

## 四、分析推理

### 1. 解题步骤

1. 根据已知条件进行逻辑分析
2. 利用排除法、代入法或图表法
3. 推出确定性的结论

### 2. 例题解析

**例题（2018联考）**

> 某单位要从甲、乙、丙、丁、戊、己6名工作人员中选派3名参加省职业技能大赛。有4位评委分别提出了自己的意见：
> （1）甲、丙二人中至少选一人；
> （2）乙、戊二人中至少选一人；
> （3）乙、丙二人中至多选一人；
> （4）甲、丁二人中至多选一人。
> 后来得知，戊因病不能参赛，并且上述4位评委的意见都得到了尊重。

**解析**：
- （1）甲或丙
- （2）乙或戊
- （3）-乙或-丙
- （4）-甲或-丁

利用-戊这个条件，得到：-戊→乙→-丙→甲→-丁，不选丙丁戊，那么就只能选择甲乙己。

## 五、归纳推理

### 1. 解题原则

| 原则 | 说明 |
|------|------|
| **话题一致** | 选项与题干话题必须一致 |
| **从弱原则** | 优选可能性选项，避免绝对化 |
| **整体优先** | 优先选择涵盖整体的选项 |
| **敏感词汇** | 注意"所有"、"都"、"一定"等绝对化表述 |

### 2. 常见错误选项

- 无中生有
- 夸大其词
- 过度推断
- 混淆概念

---

## 六、解释推理

### 1. 解题步骤

1. 找到题干中的矛盾或现象
2. 分析各选项是否能解释该矛盾
3. 选择最能合理解释的选项

### 2. 例题解析

**例题**

> 在某次考试中，有3个要求英语成绩在90分以上，有3个要求数学成绩在90分以上，但实际上只有2人同时满足两个条件。以下哪项最能解释这一现象？

**解析**：需要解释为什么要求的人数和实际满足的人数不一致，可能是因为有人同时被两个条件计算了。

## 七、数学推理

### 1. 常见题型

| 题型 | 说明 |
|------|------|
| **比例问题** | 根据比例关系进行推理 |
| **集合问题** | 利用容斥原理解题 |
| **最值问题** | 求最大值或最小值 |
| **排列组合** | 运用排列组合知识 |

### 2. 解题技巧

- 画图辅助理解
- 利用方程求解
- 代入验证

---

## 八、相似推理

### 1. 解题步骤

1. 分析题干的逻辑结构
2. 找出与题干逻辑结构相似的选项
3. 注意排除干扰选项

### 2. 常见逻辑结构

| 结构 | 说明 |
|------|------|
| **A→B** | 充分条件推理 |
| **只有B，才A** | 必要条件推理 |
| **A且B** | 联言推理 |
| **A或B** | 选言推理 |

---

> 💡 **解题技巧**：
> 1. 翻译推理：熟练掌握箭头语言和逆否命题
> 2. 真假推理：先找矛盾关系，再找反对关系
> 3. 分析推理：利用排除法和图表法
> 4. 归纳推理：注意从弱原则，避免绝对化
> 5. 所有题型都要注意话题一致原则
