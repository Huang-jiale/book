# ☕ 关于本站

> 一个安静的角落，用来存放那些不想忘记的东西。

## 关于这个博客

**知行笔记** 是我的个人博客，名字取自"知行合一"。它不追求流量，也不追求更新频率，只是我记录思考、沉淀所学的地方。

这里大致会有这么几类内容：

- **✍️ 随笔杂谈** —— 生活里的观察和一些想通的道理；
- **📖 读书笔记** —— 读过的好书，拆解、消化、再输出；
- **🎯 公考笔记** —— 我正在认真准备的一件事，顺手整理成了系统笔记。

## 为什么写博客

我始终相信一句话：**没有被记录下来的思考，等于没有发生过。** 写作会逼着我把模糊的直觉整理成清晰的逻辑，这个过程本身，就是学习最好的方式。

## 关于技术

本站使用 [docsify](https://docsify.js.org/) 搭建——纯静态、无需数据库、Markdown 直接渲染，简单又克制，正合我意。
