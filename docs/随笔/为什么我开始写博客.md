# 为什么我开始写博客

> 写作是把思考具象化的过程。

很长一段时间，我的想法都停留在脑子里——那些一闪而过的念头、读到某本书时的顿悟、解决一个难题后的复盘，最后大多都随着时间淡忘了。后来我意识到，**没有被记录下来的思考，等于没有发生过。**

## 记录，是为了对抗遗忘

我们每天接收海量信息，但真正沉淀下来的极少。写博客对我而言，首先是一个"外置硬盘"：把学过的知识、踩过的坑、想通的道理都存进去，需要时随时调用。

## 写清楚，才算真想明白

费曼说过，如果你不能把一件事简单地解释清楚，说明你还没真正理解它。写作会逼着我把模糊的直觉整理成清晰的逻辑——很多时候，写到一半才发现自己其实没想明白。这个"卡壳"的瞬间，恰恰是学习真正发生的地方。

## 给未来的自己留一封信

一年后回头看今天的文字，也许会觉得幼稚，但那正是成长的证据。这个博客不追求多少人阅读，它更像是我和自己的长期对话。

如果这些文字碰巧也能帮到路过的你，那就是额外的惊喜了。

---

*—— 记于一个想把生活过得更清醒的午后*
