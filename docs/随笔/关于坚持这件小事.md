# 关于坚持这件小事

> 真正拉开差距的，从来不是天赋，而是那些看起来微不足道的重复。

我们总是高估短期能做的事，又低估长期坚持的力量。

## 别指望一开始就有热情

很多人等"有动力了再开始"，结果永远没开始。事实恰恰相反——**行动会带来动力，而不是反过来。** 先做五分钟，状态往往就来了。

## 把目标拆到不可能失败

"每天读一小时书"容易放弃，"每天读一页"几乎不可能失败。降低启动门槛，让惯性替你工作。真正重要的是**连续性**，而不是每次的强度。

## 允许自己偶尔中断

坚持不是"一天都不能断"，而是"断了之后还能回来"。完美主义是坚持最大的敌人——漏了一天不要紧，别让它变成漏了一周的借口。

## 复盘，让重复变成迭代

单纯的重复只是重复，加上复盘才是精进。每隔一段时间问自己：哪里可以更省力？哪里其实在做无用功？

---

坚持之所以难，是因为它的回报总是滞后的。但也正因如此，它才成了少数人的护城河。

*共勉。*
