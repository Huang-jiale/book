## 📊 四大题型概览

### 1. 图形推理
- **数量类**：元素、面、角、线、点、笔画
- **位置类**：平移、旋转、翻转
- **属性类**：对称性、曲直性、封闭性
- **样式类**：叠加、遍历
- **重构类**：折纸盒、截面图

### 2. 类比推理
- **概念关系**：全同、包含、交叉、全异、并列
- **映射关系**：功能、材料、因果、顺序、条件
- **语义关系**：近义、反义、比喻、象征
- **语法关系**：主谓、动宾、偏正

### 3. 逻辑判断
- **基本逻辑原理**：逆否命题、矛盾关系、推理规则
- **推理题型**：翻译推理、真假推理、分析推理、归纳推理等
- **加强与削弱论证**：论证三要素、加强/削弱方式、力度对比

### 4. 定义判断
- **解题方法**：提取关键词、归纳特征、隐含要点、选项类聚
- **常见分类**：法律法规类、社会学类、心理学类、管理学类、经济学类、生物学类

## 🎯 核心考点速查

### 图形推理最常考
1. 一笔画判断（奇点数0或2）
2. 对称性（轴对称、中心对称）
3. 面（封闭区间）数量
4. 元素遍历

### 逻辑判断最重要
1. 逆否命题等价转换
2. 加强/削弱力度对比
3. 因果倒置识别
4. 矛盾关系判断

### 类比推理常考点
1. 概念关系辨析
2. 映射关系（功能、材料、因果）
3. 语义关系（近义、反义）

### 定义判断解题要点
1. 主体一致性
2. 提问方式（属于/不属于）
3. 题干为王原则
