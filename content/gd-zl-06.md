# 06 资料分析 · 倍数与综合分析

> 核心：甲是乙的多少倍 → 前除后；增长倍数要减一。综合分析是收尾题，用排除法提速。

## 本章核心流程图

```
A÷B → A÷B-1 → A>nB → 注意时间一致 → 综合分析题 → 先做简单项 → 单项>2分钟跳
```

## 核心口诀（原文）

> 甲是乙的多少倍，还是前面除后面。倍数计算有陷阱，增长倍数要减一。

## 核心公式

**A 是 B 的 n 倍**：n=(A)/( B)

**A 比 B 增长（多/高/超出）r 倍**：r=(A)/( B)-1

**A 超过 B 的 n 倍**：A > nB

**部分平均是整体平均的倍数**：若给部分 A1 占整体 B1 比重 c1、部分 A2 占整体 B2 比重 c2，则倍数 = (c_1)/( c_2)

## 考点拆解

### 考点 1：倍数基础问法
- **识别标志**："A 是 B 的多少倍"
- **标准步骤**：
  1. 确认时间一致（都现期或都基期）
  2. 直接 A÷B
- **速算技巧**：注意"超过 n 倍"是 >nB，不是 =nB。

### 考点 2：增长倍数陷阱（−1）
- **识别标志**："A 比 B 多/增长/高 r 倍"
- **标准步骤**：
  1. 先算 A÷B 得"是几倍"
  2. 再减 1 得"多几倍"
- **速算技巧**："是 3 倍"≠"多 3 倍"，多 3 倍 = 是 4 倍。

### 考点 3：综合分析流程
- **识别标志**："以下正确的是""不能推出的是"
- **标准步骤**：
  1. 从计算量最小的项或 C/D 项入手
  2. 用排除法，遇确定错误/正确即定答案
  3. 单题 > 2 分钟先跳
- **速算技巧**：综合题各小题独立，做对 3~4 个即可。

## 真题演练

> **example**：真题（2022 江苏 · 增长倍数）
> 【题干】2021 年 1—7 月我国原油产量 11561 万吨（同比+2.4%），7 月产量 1686 万吨；1—7 月进口原油 30193 万吨（同比−5.6%），7 月进口 4124 万吨。则 2021 年上半年，我国原油进口量比生产量多几倍？
> A. 1.6　B. 1.8　C. 2.8　D. 2.9
>
> 【解题关键】"多几倍"= 是几倍 − 1；上半年 = 1—7 月 − 7 月。
>
> 【完整解析】进口上半年 = 30193−4124 = 26069；生产上半年 = 11561−1686 = 9895；倍数 = 26069 ÷ 9895 - 1 ≈ 2.63 - 1 = 1.63。
>
> 【答案】A（1.6 倍）

> **example**：真题（倍数 · 部分平均对比）
> 【题干】2020 年末，全国艺术表演团体 17581 个，其中文旅部门所属 2060 个（占 11.7%，从业 10.75 万人占 24.6%）。平均每个文旅部门所属团体是全体的多少倍？
> A. 0.5　B. 0.8　C. 1.3　D. 2.1
>
> 【解题关键】人均倍数 = 比重之比 (24.6\%)/( 11.7\%) ≈ 2.1。
>
> 【完整解析】部分平均/整体平均 = 从业人员比重 ÷ 团体数比重 = 24.6\% ÷ 11.7\% ≈ 2.1。
>
> 【答案】D（2.1）

## 陷阱与避坑

> **⛔ 警示**：常见陷阱
> - **"是 n 倍" vs "多 n 倍"**：多 n 倍 = 是 (n+1) 倍，忘减 1 直接错。
> - **时间错位**：A 用现期、B 用基期，倍数无意义。
> - **综合题死磕**：单题超时才发现，后面简单题没时间。

> **💡 提示**：秒杀技巧
> - 出现"倍"先看问法：有"多/增长/高"就 −1。
> - 平均倍数 = 比重之比，不用分别求总量。
> - 综合分析先做"说法判断"类，往往一眼可排。

## 考场策略
- **建议用时**：倍数单题 ≤ 40 秒；综合分析 ≤ 2 分钟。
- **卡住时第一反应**：回到问法，确认"是几倍"还是"多几倍"。
- **何时放弃**：综合分析全 5 项算不清，用选项分布蒙后跳走。
