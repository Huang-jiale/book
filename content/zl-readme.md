## 🎯 核心公式速查

### 增长率相关

| 公式 | 说明 |
|------|------|
| 基期 = 现期 ÷ (1+r) | 基础公式 |
| 增长量 = 基期 × r = 现期/(1+r) × r | 百化分 |
| 增长率 = (现期-基期)/基期 | 基本定义 |
| 间隔增长率 r = r₁ + r₂ + r₁×r₂ | 两年复合 |
| 年均增长率 (1+r)ⁿ = 现期/基期 | n年复合 |
| 乘积增长率 R = R₁ + R₂ + R₁×R₂ | A=B×C |

### 比重平均数相关

| 公式 | 说明 |
|------|------|
| 现期比重 = A/B | 基础公式 |
| 基期比重 = A/B × (1+b)/(1+a) | 基期公式 |
| 两期比重差 = A/B × (a-b)/(1+a) | 升降判断 |
| 平均数增长率 = (a-b)/(1+b) | 分母是1+b |

### 速算技巧

| 技巧 | 适用场景 |
|------|---------|
| 截位直除 | A/B 形式 |
| 百化分 | 整数×百分数 |
| 化除为乘 | \|r\|≤5% |
| 线段法 | 混合增长率 |
| 尾数法 | 选项尾数不同 |

## ⚡ 备考建议

### 基础阶段（1-2周）
1. 熟记百化分速查表
2. 掌握截位直除和化除为乘
3. 理解基期、现期、增长量、增长率的关系

### 强化阶段（2-3周）
1. 专项突破间隔增长率、年均增长率、混合增长率
2. 掌握两期比重的升降判断
3. 熟练运用线段法

### 冲刺阶段（1-2周）
1. 限时套题训练
2. 总结易错点
3. 强化估算能力
