# 第七章 乘积增长率

> 💡 **核心要点**：当A=B×C时，R_A = R_B + R_C + R_B×R_C，常见于总额=单价×数量、部分=整体×比重。

## 🎯 核心公式速查表

| 关系 | 公式 | 识别标志 |
|------|------|---------|
| 总额=单价×数量 | R_额 = R_单 + R_数 + R_单×R_数 | 出现单价和数量 |
| 部分=整体×比重 | R_部 = R_整 + R_重 + R_整×R_重 | 出现占比/比重 |
| 面积=长×宽 | R_面 = R_长 + R_宽 + R_长×R_宽 | 几何图形 |

## 📖 知识点详解

### 7.1 总额=单价×数量

#### 🔹 示例1：基础计算（基础）

> **题目**：2017年长江流域播种面积下降14.9%，单产下降3.6%，求总产量下降率？
> A. 4%　B. 7%　C. 15%　D. 18%
>
> 📊 **解题流程图**：
> ```
> 总产量 = 面积 × 单产
> 
> R = R_面积 + R_单产 + R_面积×R_单产
>   = -14.9% + (-3.6%) + (-14.9%)×(-3.6%)
>   = -18.5% + 0.54%
>   = -17.96%
>   ≈ -18%
> ```
>
> ✅ **解析**：化积增长率公式，-14.9%-3.6%+0.54%≈-18%，选D。

---

### 7.2 部分=整体×比重

#### 🔹 示例1：比重变化处理（进阶）

> **题目**：2019年海洋生产总值89415亿元，增长6.2%。三次产业比重从59.1%变为60.0%，求第三产业增加值增长率？
> A. 6.4%　B. 7.1%　C. 7.8%　D. 8.5%
>
> 📊 **解题流程图**：
> ```
> 第三产业 = 总产值 × 比重
> 
> 第一步：计算比重增长率
> R_重 = (60.0%-59.1%)/59.1% = 0.9%/59.1% ≈ 1.5%
> 
> 第二步：代入乘积公式
> R_第三 = R_总 + R_重 + R_总×R_重
>        = 6.2% + 1.5% + 6.2%×1.5%
>        = 7.7% + 0.093%
>        = 7.79% ≈ 7.8%
> ```
>
> ✅ **解析**：先算比重增长1.5%，再代入公式得7.8%，选C。

## 🧩 情景模拟

### 📝 综合例题：表格数据分析

> **题目**：根据以下资料，2015-2018年固定通信业务收入同比增长的年份有几个？
>
> | 年份 | 电信业务增速 | 固定占比 |
> |------|-------------|---------|
> | 2015 | 4.2% | 60% |
> | 2016 | 5.1% | 58% |
> | 2017 | 6.8% | 57% |
> | 2018 | 7.5% | 60% |
>
> 📊 **解题流程图**：
> ```
> 固定 = 电信 × 比重
> 固定增长 ↔ R_电信 + R_重 > 0
> 
> 2015年：占比从?→60%，设前一年x，(60-x)/x = R_重
> 无法直接算，需要换年计算
> 
> 逐年计算比重增长率：
> 2015：60/占比_2014 - 1（需要假设或从表推断）
> 
> 实际方法：
> R_固定 = R_电信 + R_重 + R_电信×R_重
> 当都<10%时，近似为 R_电信 + R_重 > 0
> 
> 2015：4.2% + (60%-前占比)/前占比
> 假设2014占比57%，则R_重=5.3%，4.2+5.3>0 ✓
> 2016：5.1% + (58-60)/60 = 5.1%-3.3% = 1.8% > 0 ✓
> 2017：6.8% + (57-58)/58 = 6.8%-1.7% = 5.1% > 0 ✓
> 2018：7.5% + (60-57)/57 = 7.5%+5.3% = 12.8% > 0 ✓
> 
> 4年都增长
> ```
>
> ✅ **完整解析**：每年固定增长率都为正，4年增长，选D。

## ⚡ 速算技巧总结

| 技巧 | 适用场景 |
|------|---------|
| 忽略乘积项 | 各增长率<10% |
| 比重增长率 | (新比重-旧比重)/旧重量 |
| 判断正负 | R_B+R_C>0则整体增长 |

---

## ⚠️ 易错点提醒

- ❌ **比重变化**：R_重=(a%-b%)/b%，分母是旧重量
- ❌ **乘法关系**：确认是A=B×C，不是A=B+C
- ❌ **近似条件**：各增长率都<10%才能忽略乘积
