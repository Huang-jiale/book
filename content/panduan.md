## 前言与概述

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第1-7页

---

### 一、判断推理概述

作为行测中的重要内容之一，判断推理主要包括**图形推理、类比推理、逻辑判断和定义判断**四大题型（广东省考涉及对图形、词语概念、事物关系和文字材料的理解和阅读演绎归纳以及各类常识的运用能力），通常在公务员考试中占到**35-40题**，与言语理解一起占据了行测的半壁江山。

#### 核心特点

| 特点 | 说明 |
|------|------|
| **题量大** | 35-40题，占总分比重高 |
| **思维要求高** | 对逻辑思维能力要求较高 |
| **可塑性强** | 掌握技巧后可以快速提升 |
| **时间紧** | 要求25分钟内做完40题 |

#### 与其他题型对比

相对于其他题型而言，判断推理题对同学的逻辑思维能力要求较高，因而，在很多同学看来，尤其是很多文科的女生，觉得推理题目比较难。但是，随着公务员考试竞争日益激烈，判断推理是可以通过系统学习迅速提升的题型，必须引起足够的重视。

---

### 二、为什么要考判断推理

#### 1. 判断思维能力的定义

判断思维能力是人的思维能力的核心部分，其涵义是指人们根据一定的先知条件，通过自己拥有的知识、思维进行判定、推断，对事物得出自己的结论的能力。

#### 2. 考试意义

- 通过对一个人的判断推理能力的判定，能够反映出他对事物的本质及事物之间联系的认知能力的高低
- 公务员所从事的行政管理工作的对象、内容非常复杂，需要良好的逻辑思维作为基础
- 这是公务员入职的基本素质之一，如果逻辑思维能力不达标，就难以胜任公务员工作

#### 3. 与日常逻辑的区别

日常生活中我们也有"逻辑感"，但这种感性的、模糊的、零散的逻辑知识不足以应对考试：
- 系统学习可以帮助发现考题的考点及陷阱
- 能够快速高效地完成答题
- 避免因"逻辑感"导致的20%错误率瓶颈

---

### 三、常见误区

#### 误区一："不学逻辑也能做对"

**表现**：有一部分同学未曾学习过任何逻辑知识，但在做考试真题时并没有感到有很大的困难，所以认为学习逻辑知识没有用。

**分析**：
- 确实，生活和学习的丰富经历能教会我们一些简单的、朴素的、模糊的、零散的逻辑知识
- 但是，仅靠"逻辑感"对于应对判断推理是不够的

**为什么"逻辑感"不够：**

1. **知识盲点**：没有系统复习，存在很多逻辑知识盲点，导致部分题型一直做错
2. **难度增加**：公务员考试试题难度有稳步加大趋势，"逻辑感"往往太简单
3. **时间压力**：行测答题速度要求很高（40题/25分钟），仅靠"逻辑感"会耗费过多时间

#### 误区二："要系统深入学习全部逻辑知识"

**表现**：认为逻辑知识非常重要，强迫自己系统而深入地学习全部逻辑知识。

**问题**：
- 常因为学法不得要领而事倍功半
- 即便全面掌握逻辑知识，也会因投入时间过多而影响其他模块备考
- 很多培训机构讲授逻辑知识时没能很好结合公务员考试实际需要

#### 正确的学习方法

**原则**：只有公务员考试会涉及的逻辑知识原理（绝对不是晦涩难懂的概念本身）才是需要掌握的。

**目标**：将复杂问题简单化，摒弃概念、学术、专业的东西，掌握最实用的高分策略。

---

### 四、四大题型介绍

#### 题型分布

| 题型 | 题量（国考） | 难度 | 核心能力 |
|------|-------------|------|----------|
| **图形推理** | 10题 | ⭐⭐⭐ | 观察、空间想象 |
| **类比推理** | 10题 | ⭐⭐ | 词语关系分析 |
| **逻辑判断** | 10题 | ⭐⭐⭐⭐ | 逻辑推理能力 |
| **定义判断** | 10题 | ⭐⭐ | 信息提取能力 |

#### 各题型特点

##### 1. 图形推理
- 来源于国外智商测试
- 不依赖于具体事物，较少受知识储备和文化背景制约
- 主要依靠空间想象能力
- 被称为"文化公平"测试

##### 2. 类比推理
- 考查词语概念之间的关系
- 需要掌握外延概念、内涵映射、语法语义等多方面知识

##### 3. 逻辑判断
- 包括翻译推理、真假推理、分析推理、论证推理等
- 需要掌握基本的逻辑原理和命题推理规则

##### 4. 定义判断
- 考查对定义的理解和信息提取能力
- 需要掌握提取信息要点、归纳关键信息的方法

---

### 五、备考建议

#### 1. 系统学习基本逻辑知识
- 掌握公务员考试涉及的逻辑原理
- 不追求学术深度，注重实用性

#### 2. 大量练习历年真题
- 通过练习发现自己的薄弱点
- 熟悉常见考点和陷阱设置

#### 3. 总结解题技巧
- 形成自己的解题思路
- 提高解题速度和准确率

#### 4. 合理分配时间
- 判断推理40题建议25分钟内完成
- 平均每题37.5秒

---

> 💡 **学习提示**：判断推理是行测中区分度较高的模块，掌握系统方法后可以快速提升成绩。建议按照"图形推理→类比推理→逻辑判断→定义判断"的顺序进行学习，循序渐进。

## 图形推理-数量类①（素、面、角）

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第8-18页

---

### 一、图形推理概述

#### 1. 大纲分析

每道题给出一套或两套图形，要求报考者通过观察分析找出图形排列的规律，选出符合规律的一项。

#### 2. 图形推理的本质

图形推理指的是由已知图形总结出规律，进而确定未知图形的思维过程。它来源于国外智商测试，由于这种题型仅仅是观察图形，不依赖于具体的事物，也较少受到知识储备和文化背景的制约，往往靠的是空间想象能力，因此又被人们称之为"文化公平"测试。

#### 3. 考点设置原则

通过一个描述来理解图形推理的考点来源：

> "一张白纸，左上角画一个正方形，右上角画一个圆，标记正方形的左下角"

这句话包含四个方面的内容：

| 考点 | 说明 | 示例 |
|------|------|------|
| **图形数量** | 图形的个数 | 一个正方形、一个圆 |
| **图形位置** | 图形的相对位置 | 正方形在左上角、圆在右上角 |
| **图形属性** | 图形的形状特征 | 正方形（对称性、曲直性等） |
| **图形样式** | 图形的组合方式 | 每行都有正方形和圆形 |

> 💡 **核心要点**：解决图形推理的关键是数量、位置、属性和样式四大考点。

#### 4. 判断准则

在做题时，根据题干图形的组成特点判断可能的考点：

| 题干特征 | 最可能考点 |
|----------|-----------|
| 图形组成比较凌乱 | **数量类**规律 |
| 图形组成完全相同 | **位置类**规律 |
| 图形组成有些类似 | **属性类**规律 |
| 图形间有明显关联性 | **样式类**规律 |

---

### 二、数量类图形推理概述

#### 1. 什么是数量类图形推理

数量类图形推理，顾名思义就是要数数量，主要包括**计数对象**和**数列计算规律**两部分内容。

#### 2. 计数对象（素→面→角→线→点）

数量类图形推理的考点遵循"素、面、角、线、点"的筛选顺序，注意顺序不要搞反，是从素开始，筛到点。

```
筛选顺序：素 → 面 → 角 → 线 → 点
```

---

### 三、计数对象详解

#### （一）素（元素）

**定义**：素，即元素，我们往往把图形中相连的一个整体叫做一个元素。

##### 考点类型

| 考点 | 说明 |
|------|------|
| **元素种类** | 图形中不同元素的种类数 |
| **元素个数** | 图形中元素的总数 |
| **特殊元素** | 每组图形中都有的共性小元素 |

##### 注意事项

- 在公务员考试中，即使某个图形很复杂，但只要连在一起，一律视作一个元素
- 例如："品"字有3个元素，"田"字有1个元素
- 特殊元素考点：题干中每一组图形都有一种共性小元素或共性小图形

##### 例题解析

**例题1（2016国考）**

```
☆O  ☆00  ☆  O  ☆ ☆ ☆
O O      ☆   ☆ ☆
☆ ☆ ☆
```

**解析**：观察题干图形，元素个数分别311, 221, 311, 221，呈周期排列，那么选项应该是311组合，选择B选项。

**例题2（2018北京）**

**解析**：观察题干图形，每一组图形的元素种类都是4种，选择A选项。

**例题3（2016广东）**

**解析**：本题考查元素的个数，分别是4、3、2、3、？，本题就是元素个数的规律对称，问号处应该填"4"，选择B选项。

**例题5（2017联考）**

**解析**：本题考查特殊元素，即每幅组图形里都有一个共性小元素（共性小图形）三角形，答案选择A选项。

---

#### （二）面（封闭区间）

**定义**：在公务员考试中，涉及的面就是一个图形里面不连通的部分，也叫封闭区间。

##### 考点类型

| 考点 | 说明 |
|------|------|
| **封闭区间数量** | 图形中不连通部分的数量 |
| **面积关系** | 阴影部分面积与整体图形面积的关系 |

##### 涉及"面积"的题目特点

图形中含有阴影部分时，首先考虑阴影部分面积与整体图形面积之间的关系：
- 阴影部分的面积是整体图形面积的二分之一
- 两个图形阴影部分的面积之和等于第三个图形阴影部分的面积

##### 例题解析

**例题1（2012国考）**

**解析**：本题是一组汉字，在图形推理中一定要"把字看成图"，千万不要研究汉字本身的含义。考查封闭区间，面的数量2、3、4、5、（6），选择B选项。

**例题2（2015联考）**

**解析**：各图元素构成不同，考虑数量规律。各图面（封闭空间）的数量分别为4、5、6，需要选择7个面的选项；另每个图形的最外边主体图形的边数分别为3、4、5，应选主体为6边形的图形。

**例题4（2018深圳）**

**解析**：本题为3×3分组题目，观察封闭区间，左边一组封闭区间数量分别为1、2、3，呈等差数列，右边一组分别为4、5、？，依然呈等差数列，选6个封闭区间的C选项。

---

#### （三）角

**定义**：角分为锐角、直角和钝角三种。

##### 公务员考试中角的注意事项

1. 公务员考试中考到的角一定是**小于180度**的，大于180度的角一律不用考虑
2. 绝大多数题目只考**内角**，但不是所有题目都是只考内角
3. 有些题目会单独考锐角和直角的个数
4. **特征图形**：扇形、多边形中间无缘无故加不相连的线、不相交的直线乱绞丝多为数角

##### 角的常见考法

| 考法 | 说明 |
|------|------|
| **全部角** | 数图形中所有角的数量 |
| **锐角** | 只数锐角的个数 |
| **直角** | 只数直角的个数 |
| **直角三角形** | 数直角三角形的个数 |

##### 例题解析

**例题1（2010江苏）**

**解析**：本题就是前面提到的只考锐角的情况，而且出现了特征图形乱绞丝，指引我们考点是角。观察题干，在这个九宫格图形中，从横向数，图形中锐角的个数依次为1、2、3、4、5、6、7、8、（9），选择含有9个锐角的B选项。

**例题2（2012广东）**

**解析**：题目中出现了类似于扇形的特征图形，优先考虑数角。的角的数目分别为2、3、4，接下来的图形应该包含5个角。注意A选项，中间部位在两条直线之间夹了一条曲线，就不再成角，应特别注意。

**例题4（2013国考）**

**解析**：数直角三角形个数（或者直角个数），每个图形都由两个三角形组成，且都包含直角三角形。①④⑥中都包含两个直角三角形，②③⑤中都包含一个直角三角形，选择B选项。

**例题5（2015联考浙江）**

**解析**：本题考查数直角数，题干图形分别包含1、2、3、4、（5）个直角，应选择一个直角数为5的图形。

---

### 四、出题形式总结

#### 1. 4+1形式（最常见）

题干中有四幅图，从四个选项中选择一幅构成规律。

**例题**：此题考查角或者直线数量，从左到右分别为3、4、5、6、（7），选择A选项。

#### 2. 3+3形式

分为左右两组图形，左右两组图的规律可以不完全相同，但一定有相似性。

#### 3. 九宫格形式

![九宫格图形示例](判断推理知识库-备考手册.assets/九宫格图形示例.svg)

观察规律：横看、竖看、米字型、S形、O形、G形、e形。最常见为横看、竖看、米字型。

#### 4. 分类分组形式

国考中每年考3-5道，题目给6个图形，编号①-⑥，把6个图形依照共同点分为两组。

**例题（2017年国考副省级卷）**：本题考查图形的笔画数，①③⑤为两笔画图形，②④⑥为一笔画图形，选择C选项。

#### 5. 5+1形式

在4+1题型常见的规律之外，还有两种特殊情况：
1. 六幅图可以分成两组进行观察（3+3的形式）
2. 左边三幅图和右边三幅图的规律关于中轴线对称

#### 6. 2+2形式

分为左右两组图形，往往不考图形的数量问题，只考图形的位置和属性问题。

#### 7. 异形（了解）

形式多变，往往难度较低。

---

> 💡 **解题技巧**：当题干图形组成比较凌乱时，优先考虑数量类规律。按照"素→面→角→线→点"的顺序逐一筛选，找到正确的计数对象后，再分析数量之间的计算规律。

## 图形推理-数量类②（线、点与计算规律）

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第19-28页

---

### 一、线

#### 1. 线的定义

图形推理中提到的线，不同于数学概念里的直线或者线段。在公考中，**只要经过一个拐点，就把它定为一段**，注意这里的拐点是不平滑的点。

**图示说明**：
- 图1：有拐点 → 由两条直线组成
- 图2：拐弯平滑 → 由一条曲线构成

#### 2. 线的四个考点

| 考点 | 说明 |
|------|------|
| **线的条数** | 包含曲线的条数和直线的条数 |
| **线的曲直性** | 线条是直线还是曲线 |
| **汉字的笔画数** | 按照汉字书写规定得出的笔画数 |
| **一笔画问题** | 探讨图形能否用一笔画出来 |

#### 3. 线的注意事项

**汉字的笔画数**：不同于传统意义上图形的线条数
- "正"是5笔
- "天"是4笔
- "红"是6笔

#### 4. 一笔画问题详解

##### 核心概念：奇点

**定义**：以点为中心进行观察，如果从一个点引出线的条数是奇数条，则该点是奇点，反之是偶点。

##### 一笔画判定规则

| 规则 | 说明 |
|------|------|
| ① | 奇点个数是0或2的图形可以一笔画画出，除此之外都不行 |
| ② | 笔画数 = 奇点个数 ÷ 2 |
| ③ | 奇点一定是成对出现的（偶数个） |
| ④ | 端点也是奇点 |
| ⑤ | 奇点连的线可以是曲线 |
| ⑥ | 两个互不相连的一笔画图形组成，是两笔画 |

##### 例题解析

**例题1（2017国考）**

**解析**：本题单独考查曲线条数，每行曲线条数都为1、2、3，选择三条曲线的B选项。

**例题2（2016吉林）**

**解析**：本题是汉字的笔画与图形的线条数交叉考查，分别为3、4、5、6，呈递增的等差数列，选择7笔的B选项。

**例题5（2015国考）**

**解析**：由图②这个典型的"田"字变形，可以提示考虑"笔画"考点。①②⑥图形最少都可两笔画成；③④⑤图形最少都可一笔画成。图中涉及的奇点如下图所示：

```
②  ③  ④  ⑤  ⑥
```

**例题6（2017年国考）**

**解析**：后发现②是日字形变形，④图形为"田"字变形，考虑笔画数考点。图①③⑤的奇点数均为4，图②④⑥中奇点数为2，③无奇点数。即①③⑤为两笔画图形，②④⑥为一笔画图形。

---

### 二、点

#### 1. 点的四种类型

公务员考试中的点，涉及四种：

| 类型 | 定义 | 示例 |
|------|------|------|
| **端点** | 连一条线的点 | 一条线段上有两个端点 |
| **拐点** | 连两条线的点 | "△"有三个拐点 |
| **交点** | 连三条及三条以上线的点 | "田"有4个拐点、5个交点 |
| **切点** | 直线与曲线、曲线与曲线相切的点 | - |

> 💡 **注意**：目前的公务员考试，拐点和交点一般不做区分，可以将拐点当做交点看。

#### 2. 点的新型考法（难度加大）

| 考法 | 说明 |
|------|------|
| **直直交点** | 只考查直线与直线交点的数量 |
| **直曲交点** | 只考查直线与曲线交点的数量 |
| **曲曲交点** | 只考查曲线与曲线交点的数量 |
| **内外交点** | 分开考查图形外部轮廓和内部部分交点的数量 |
| **特征图形** | 出头点、半闭合图形、曲线乱绞丝、多边形中间有不相连的线头等 |

#### 3. 例题解析

**例题1（2018北京）**

**解析**：本题含有半开半闭图形、多边形中间有不相连的线头等特征图形，优先考虑交点数量。本题考查单独数曲线与直线交点，分别为2、3、4、2、3、？，选择四个曲直交点的C选项。

**例题2（2017江苏）**

**解析**：本题的特征为多边形中间连线位置不同构造不同点，考虑交点个数为6、7、8、9、10、？，选择11个交点的B选项。

**例题5（2018国考）**

**解析**：本题含有多边形中间有不相连的线头等多种特种图形，考虑数交点数。分内外数，图形内部交点分别为0、1、2、3、4、？，选择内部交点个数为5个的C选项。

### 三、计算规律

#### 1. 数列规律

在图形推理中一共涉及到七种数列规律：

| 数列类型 | 说明 | 重要性 |
|----------|------|--------|
| **等差数列** | 相邻两项之间做差，差相等 | ⭐⭐⭐ 重点掌握 |
| **对称数列** | 数字的规律呈对称性 | ⭐⭐⭐ 重点掌握 |
| **乱序数列** | 等差数列里面的数字被打乱 | ⭐⭐⭐ 重点掌握 |
| **等比数列** | 相邻两项之间做商，商相等 | ⭐⭐ 了解 |
| **周期数列** | 数量规律呈周期性 | ⭐⭐ 了解 |
| **递推数列** | 前一项（几项）与后一项的关系 | ⭐⭐ 了解 |
| **同余数列** | 奇偶交替或都是某数的倍数 | ⭐⭐ 了解 |

##### ① 等差数列

相邻两项之间做差，如果差相等，就叫做等差数列。注意常数列是公差为0的等差数列。

**例题（2011浙江）**

**解析**：元素组成凌乱，数曲线数，已知图形曲线数分别是1、2、3、4、（5），呈等差数列。

##### ② 对称数列

数字的规律呈对称性。比如：4、3、2、2、3、（4）这样的数列。

**例题（2016广东）**

**解析**：元素个数分别为4、3、2、3，呈对称数列，问号处图形应包含4个元素。

##### ③ 乱序数列

一个等差数列里面的数字被打乱，然后从中剔除一个数字，让我们从选项中找到这个数字。

**注意**：在公务员考试中，乱序数列只考连续的自然数数列。

**例题（2008国考）**

**解析**：出头点（端点）分别为3、5、1、2、0、？，前面一组数据是从0-5，中间唯独缺了4，是乱序规律，选有4个出头点的C选项。

##### ④ 等比数列

相邻两项之间做商，商相等。

**例题（2009年北京）**

**解析**：考查线的数量，分别是8、16、32；1、2、（4），成比数列选择C选项。

##### ⑤ 周期数列

数量规律呈周期性。题干中图形个数一定是偶数个。

**例题（2016年广东）**

**解析**：小黑块移动的规律为1→2→4→5→7，分别移动1、2、1、（2），移动的步数呈周期数列。

##### ⑥ 递推数列

| 类型 | 说明 | 示例 |
|------|------|------|
| 递推和数列 | 前两项的和等于第三项 | 1、2、3、5、8 |
| 递推积数列 | 前两项的乘积等于第三项 | 1、2、2、4、8 |
| 递推差数列 | 前两项的差等于第三项 | 10、6、4、2 |
| 递推商数列 | 前两项相除的商等于第三项 | 9、3、3、1、3 |

##### ⑦ 同余数列

| 类型 | 说明 | 示例 |
|------|------|------|
| 奇偶数列 | 偶数、奇数交替出现 | 4、3、6、5、2、1 |
| 倍数数列 | 都是某数的倍数 | 3、3、6、9、3 |

---

#### 2. 九宫格运算

在九宫格或者"3+3"题型中，常见两种运算关系：

| 运算类型 | 说明 | 示例 |
|----------|------|------|
| A±B=C | 前两个数据的和/差为第三个数据 | 第一行：3、5、8 |
| A±B±C=常数 | 三个数据作运算得到一个常数 | 第一行：2、4、6（和为12） |

> 💡 **注意**：A±B±C=常数的情况下，每行得到的数据都是同一个常数，绝对不可以是等差数列。

**例题1（2011年江苏）**

**解析**：九宫格交点有直线与直线的交点、直线与曲线的交点。第一列直线交点数分别是5、1、6，第二列分别是0、8、8，前两个相加等于第三个（5+1=6，0+8=8）。

---

#### 3. 多元换算

题干中给出2到3种图形，先将小图形转换成同一个形状，然后找各项之间的数量性关系。

##### 解题方法

| 方法 | 说明 |
|------|------|
| **方程法**（万能） | 将一种图形看成1，另一种看成X，用X表示每组的数量 |
| **逆推法** | 选中两组图形，根据等差/等比数列性质"逆推"换算关系 |

**例题1（2012年江西）**

**解析**：
- 方程法：假设星星为1，圆为X，数列变成：2+6X, 1+3X, 3+X, 4, ?
- 第一项是第二项的两倍，是等比数列
- 1+3X = 2×(3+X)，解得X=5
- 原数列变为：32、16、8、4、（2）

---

#### 4. 特殊计数规则

##### ① 分样式计数

将题干中的图形分成不同的样式进行计数：
- 不同形状的元素分开计数
- 曲线和直线分开计数
- 曲线与直线交点、直线与直线交点分别计数

**例题1（2010贵州）**

**解析**：查图像中直线和曲线的数量差。题干图形直线和曲线的数量差是2、1、0。

**例题3（2018江苏）**

**解析**：单一观察素面角线点都没有明显规律，但分别数出图形的外部轮廓线条数量为4、3、4、5、6，封闭区间数量为2、1、2、3、4，外部轮廓-封闭区间=2。

##### ② 分位置计数

根据不同位置分别计数：分内外、上下、前后等。

**例题1（2010年新疆）**

**解析**：考查外部图形元素个数与内部图形元素个数的数量关系。

**例题5（2016广东）**

**解析**：本题考查分上下计数，每一组图形都能分成上下两部分，且上下部分小黑块的数量相差为1，小白块的数量相差也为1。

##### ③ 重叠计数

重叠计数主要包括三种图形：角、三角形、正方形（"重叠三友"）。

**角的示例**：在传统计数时只数∠1和∠2，但在重叠计数里，∠1和∠2共同构成了∠3，所以一共有3个角。

**例题1**

**解析**：重叠数角，题干中图形角的数量分别为：3、5、7、8、4、（？），是乱序数列，问号处选择有6个角的C选项。

**例题3**

**解析**：本题考查正方形的数量，需要重叠计数，数量分别是1、2、3、4、5、6、7、8、（9），选择有9个正方形的A选项。

---

> 💡 **解题总结**：数量类图形推理的解题关键是：
> 1. 按照"素→面→角→线→点"的顺序筛选计数对象
> 2. 掌握七种数列规律
> 3. 注意九宫格运算、多元换算和特殊计数规则
> 4. 大量练习，提高识别特征图形的能力

## 图形推理-位置类与属性类

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第29-52页

---

### 一、位置类图形推理概述

#### 1. 何时考虑位置类考点

当题干中几组图形**相差不大或者完全相同**的时候，考查数量类考点的概率就很低，此时很大可能是考查位置类考点。

#### 2. 位置类的两大内容

| 内容 | 说明 |
|------|------|
| **静态位置关系** | 图形间相对位置不变，考虑位置规律的相似性 |
| **动态位置变化** | 元素运动的情况，包括平移、旋转、翻转 |

---

### 二、静态位置关系

#### （一）相对位置

如果题干中只有两个元素，多为考查位置关系。两球间的关系无外乎四种：

```
●○    ● ○    ●⊚    ●⊛
相离    相切    相交    内含
```

##### ① 相离

两个元素相离，要看他们的结构：
- 左右相离
- 上下相离
- 是否相邻

**例题1（2011年国考）**

**解析**：考查相同元素相离。每个图形中都有两个元素相同，相同元素有的是相邻的，有的是隔开的，将相邻的分为一组（②③④），隔开的分为一组（①⑤⑥）。

**例题4**

**解析**：观察题干中的汉字，都是左右结构，选择D选项。

##### ② 相切

图形中的相切关系，主要分为内切和外切，要特别注意切点位置的变化情况。

**例题2（2010国考）**

**解析**：图形中均含有两个图形，大图包含小图，小图和大图相切或共线，小图在大图内的位置（切点位置）按照顺时针变化。

**例题6（2018国考）**

**解析**：题干每组图形均由两个小图形构成，小图形间关系为相交、相切、相交、相切、相交，呈周期排列，？处应为相切关系。

##### ③ 相交

两个考点需要注意：
1. 图形间是以一个点相交还是多个点相交
2. 相交部分的面积和形状

**例题1（2011江苏）**

**解析**：九宫格中给出的八个图，任意相邻的两个小四边形都只有一个交点，均没有出现公共边。

**例题3（2012江苏）**

**解析**：题图形均由两个几何图形构成，重叠部分均小于组成图形的一半。

##### ④ 内含

指一个图形被另外一个图形含在里面的情况。

**例题（2012河北）**

**解析**：观察四个图形中内部图形与外部图形圆的关系，仅C项直线与圆相交，其他内部图形与外圆是相对独立的两部分。

---

#### （二）功能元素

功能元素分为：点、线、箭头、其他元素，功能元素出现时会有明显的"抓眼球"特征。

##### 功能元素类型

| 类型 | 功能 |
|------|------|
| **功能点** | 标记空间大小、方位上下左右、样式（直角、长短线、直曲线等） |
| **功能线** | 连接其他元素，使之成一定的规律 |
| **功能箭头** | 起指示、提示等作用 |

##### 处理技巧

找到共性小元素，通过小元素周边信息来判断选项。功能元素能标记的内容为：**大小、位置、样式和数量（连通）**。

##### 例题解析

**例题1（2018浙江）**

**解析**：题目组图都有一个明显的小黑球"抓眼球"，考虑功能点。①②④图形小黑点都被一个图形包裹，③⑤图形小黑点都被两个图包裹。

**例题4（2017国考）**

**解析**：题干六组图形中都有一个小三角形和一个小白球"抓眼球"。①③④图形小三角形在最大的空白面里面，②⑤⑥图形小圆球在最大的空白面里面。

**例题5（2017国考）**

**解析**：观察小黑点在图形中的位置发现：①③⑤图形中小黑点在线上，②④⑥图形中小黑点在交点上。

**例题9（2017江苏）**

**解析**：每幅图都有一条特别的斜线"抓眼球"，功能线都是从最短竖线的底部连到最长竖线的顶部。

---

### 三、动态位置变化

#### （一）平移

##### ① 行列移动

小黑球沿着横行或者纵列移动。

**四大重点知识**：

| 重点 | 说明 |
|------|------|
| **特征** | 各图元素组成基本相同，局部位置变化明显 |
| **步数** | 常数列、等差数列、周期数列 |
| **方式** | 循环跑（从一端穿出从另一端穿回）或折返跑（碰壁折回） |
| **载体** | 九宫格、十六宫格 |

**例题1（2016河南）**

**解析**：采用标号法，分别给小黑块标上1、2、3、4、5，发现1号做从左到右的循环跑，2号和3号在左右震荡，4号和5号在做逆时针旋转。

##### ② 环形移动

小黑块围绕图形的外圈做旋转的环状移动，分为一层环形和两层环形。

- 以8宫格为载体：看成两个"田"字拼接
- 以16宫格为载体：分成内外两层观察

**例题1（2017国考）**

**解析**：每次移动两个格子的逆时针移动。

**例题6（2015国考）**

**解析**：十六宫格题目，分内圈和外圈观察。圆圈只在最外圈出现，每次逆时针移动2格；内圈小线头的端点在做顺时针运动，每次移动1格。

##### ③ 移动视窗

多个图形按照一定顺序排列，每次只能看到少部分图形，像在窗户里观察。

**特点**：第一组的后两位一定与第二组的前两位相同。

##### ④ 重心移动

观察图形中重心的位置变化，涉及重心考点的题目轮廓一定非常简单。

##### ⑤ 切割移动

将一个复杂图形从中间切开，左右或上下两部分做相对运动。特别注意通过切割后，**刀口是否保留**。

**例题1**

**解析**：把第一个图分成两个相同直角梯形相互靠拢然后渐离得到第二个和第三个图。刀口是保留的。

---

#### （二）旋转

图形在同一平面内发生转动，主要有顺时针旋转和逆时针旋转两种。

**技巧**：为方便观察，常用"箭头"来表示图形的方向。

**例题1（2012上海）**

**解析**：图形从左到右外圈依次顺时针旋转90度，次外圈依次旋转180度，内圈依次逆时针旋转90度。

**例题2（2017东）**

**解析**：把时针、分针和秒针看成三个箭头，分别观察旋转方向和步数。

---

#### （三）翻转

##### 翻转与旋转的区别

| 类型 | 发生维度 | 说明 |
|------|----------|------|
| **旋转** | 同一平面内 | 图形发生转动 |
| **翻转** | 三维空间内 | 围着轴在三维空间内转动 |

##### 时针法判定翻转

通过观察图形的时针方向有无发生变化，来判断其翻转情况。

**例题1（2012江西）**

**解析**：用时针法判断，第一组图形前后两者为上下翻转关系。

**例题4（2018浙江）**

**解析**：本题为纵向观察，第一行图形顺时针旋转180度得到第二行图形，第二行图形上下翻转得到第三行图形。

---

### 四、属性类图形推理

#### 1. 对称性

##### 对称性分类

| 类型 | 定义 | 特征 |
|------|------|------|
| **轴对称** | 沿某条直线折叠，两旁部分互相重合 | 有对称轴 |
| **中心对称** | 绕某点旋转180°与另一图形重合 | 对应点连线过中心点 |
| **既是轴对称又是中心对称** | 两者兼具 | - |

##### 中心对称特征图形

S、8、H、平行四边形、偶数个角的规则图形、汽车标志、太极图

##### 常见考点

- 轴对称图形考查对称轴条数和方向
- 奇数个角的图形都不是中心对称图形

##### 新考点

1. 同一元素内不同小图形对称轴之间的关系
2. 同一图形内对称轴与图形中线条的关系（是否重合）
3. 同一图形内对称轴与图形中小图形间关系（是否有两个相同图形分列两侧）

##### 例题解析

**例题1（2015天津）**

**解析**：①②⑥仅包含1条对称轴，③④⑤包含多条对称轴；或者①②⑥仅为轴对称，③④⑤不仅轴对称且中心对称。

**例题4（2016国考）**

**解析**：第一行图形对称轴数量均为一条，方向分别为横、斜、竖，第二行同理，第三行？处应选对称轴方向为横向的图形。

**例题11（2018国考）**

**解析**：左右两组图形都由两个对称的小图形构成，左边一组小图形间对称轴呈平行、45度夹角、垂直的关系，右边一组同理。

**例题12（2018北京）**

**解析**：题干所有的图形都是轴对称图形，且每幅图形对称轴都与图形内部一条线条重合。

---



![图：轴对称看对称轴，中心对称看旋转180°重合。](判断推理知识库-备考手册.assets/r_sym.svg)



#### 2. 曲直性

曲直性考查的是构成图形的线条是曲线还是直线，分为：
- 全是曲线
- 全是直线
- 两者都有

**注意**：这里的曲直性强调是图形的性质，与"素面角线点"里面数线条数量的区别。

##### 例题解析

**例题1（2016河南）**

**解析**：题干所有的图形都是直线图形，而选项ACD含有曲线，根据曲直性选择B选项。

**例题4（2017国考）**

**解析**：题干中每幅图形均由上下两个部分组成，且上下两个部分组成的线条样式不同。曲线图形和直线图形在上下两部分交叉出现。

**例题6（2018浙江）**

**解析**：②④⑥全为直线图形，①③⑤既有曲线又有直线图形。

---

#### 3. 封闭性

封闭性考查的是图形的封闭和开放情况：

| 类型 | 说明 | 示例 |
|------|------|------|
| **封闭** | 完全封闭的图形 | 字母"O" |
| **开放** | 开放的图形 | 字母"k" |
| **半封闭** | 封闭图形加出头直线 | 字母"R" |

##### 例题解析

**例题1（2010新疆）**

**解析**：已知图形中奇数项图形是开放的，偶数项图形是全封闭的。

**例题2（2015国考）**

**解析**：④⑥图形都有封闭区域；②③图形都没有封闭区域，可以按照开放性和封闭性进行分组。

**例题7（2018联考）**

**解析**：①④⑥都含有封闭图形，②③⑤都是全开放图形。

---

#### 4. 凹凸性

| 类型 | 定义 | 示例 |
|------|------|------|
| **凸图形** | 连接内部任何两点的线段与边界都没有交点 | "○" |
| **凹图形** | 存在两点连线与边界有交点 | "☆" |

**注意**：涉及凹凸性的题目，题干图形轮廓一定非常简单。

**例题（2012江西）**

**解析**：题干中所有图形均为凸图形，选择D选项。

---

### 五、样式类图形推理

#### 1. 样式遍历

遍历，是将图形或图形的属性都经历一遍的意思。

##### 三种情况

| 类型 | 说明 |
|------|------|
| **横行遍历** | 每行包含所有样式，缺谁补谁 |
| **对应遍历** | 对应位置的图形经历所有样式 |
| **补齐遍历** | 补全缺失的样式 |

##### 例题解析

**例题1（2010国考）**

**解析**：以行为单位，考虑单元素的遍历。每一行三幅图形均有一个相同的元素，第一行都有圆形，第二行都有三角形，第三行都有平行四边形。

**例题2（2016河南）**

**解析**：第一、二行，每行图形都由轮廓相同的左、中、右三个部分构成，每行均出现三个"空白条"、一个"阴影图"、两个"星图"、一个"四个圆圈图"区域，考查横行遍历。

**例题4（2017四川）**

**解析**：3×3分组题目，左边一组图形每一种小图形都有全黑、全白、阴影三种填充形式，右边一组相同的规律。

---

> 💡 **解题总结**：
> - **位置类**：图形组成相同，考虑位置（静态或动态）
> - **属性类**：图形组成类似，考虑属性（对称、曲直、封闭、凹凸）
> - **样式类**：图形间有明显关联，考虑样式（遍历、运算）
> - 掌握时针法判断翻转、标号法判断移动是重要技巧

## 图形推理-样式类与重构类

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第53-82页

### 一、样式类图形推理

#### 1. 样式遍历

遍历，是将图形或图形的属性都经历一遍的意思。包含三种情况：

##### （1）横行遍历

每行包含所有样式，缺谁补谁。

**例题1（2010国考）**

**解析**：以行为单位，考虑单元素的遍历。每一行三幅图形均有一个相同的元素，第一行都有圆形，第二行都有三角形，第三行都有平行四边形。

**例题2（2016河南）**

**解析**：第一、二行，每行图形都由轮廓相同的左、中、右三个部分构成，每行均出现三个"空白条"、一个"阴影图"、两个"星图"、一个"四个圆圈图"区域，考查横行遍历。

##### （2）对应遍历

两组图形中，在相同的位置具有明显的相同性质。

**例题1**

**解析**：考查对应属性遍历。左边图形小黑点的位置为上、中、下，数量呈等差，同理右边×号的位置也为上、中、下。

##### （3）补齐遍历

把缺失的图形进行补齐之后，规律变得非常简单。补齐遍历的题目规律都具有周期性。

**例题1**

**解析**：直接观察每一行的遍历规律不容易观察，但补齐之后：
- 图形为：三角形、平行四边形、圆、正方形、三角形...四种图形为周期循环
- 阴影为：黑白、全白、隐形、全黑、黑白...四种阴影为周期循环

**例题2（2016联考）**

**解析**：题干每个图形都分为三部分：外部轮廓、中间填充和内部小图形。外部轮廓呈现圆、菱形、正方形的周期性；中间填充呈现全白、阴影、全白的周期性。

---

#### 2. 样式运算

与样式遍历不同，图形通过运算后会改变样式的形状。

##### （1）简单叠加

两幅图直接叠加，往往结合旋转和翻转进行考查。

**例题1（2011北京）**

**解析**：第一组图中，前两图简单叠加后逆时针旋转90°即为第三个图形。

**例题3（2018上海）**

**解析**：观察四个选项发现，我们要选的答案为前面三个图形进行叠加后的图形，前三图简单叠加后的结果为C选项。

##### （2）运算叠加

| 类型 | 说明 |
|------|------|
| **去同存异** | 两幅图叠加，去掉相同的线条，保留不同的线条 |
| **去异存同** | 两幅图叠加，去掉不同的线条，保留相同的线条 |

**例题1（2015国考）**

**解析**：考查叠加，去同存异。第一组左边图形顺时针旋转90度后与第二组图形叠加，去同存异后得到第三组图形。

**例题4（2015广东）**

**解析**：第一组图形中图一与图二去异存同得到图三。

##### （3）黑白叠加

小黑块与小白块之间的叠加。

**注意区分**：
- 小黑块运动类：黑块数量较少、图形间黑块数量变化不大
- 小黑块叠加类：位置没规律、数量变化大、一般不用16宫格作为载体

**四种情况**：黑+黑、黑+白、白+黑、白+白

**例题1（2012广州）**

**解析**："米"字型叠加，相同颜色部分叠加后变为白色，不同颜色部分叠加后变为黑色。

**例题2（2017国考）**

**解析**：黑白运算规律：同色为白，异色为黑（同白异黑）。

##### （4）特殊叠加

| 类型 | 说明 |
|------|------|
| **切割或翻倍后叠加** | 图形切割或翻倍后再叠加 |
| **按优先级不同叠加** | 不同元素有优先级顺序 |
| **A+B=C得新结果式叠加** | 两图叠加产生新结果 |

**例题3（2012广东）**

**解析**：叠加规律：↑>↓>←>→，即优先顺序为上箭头>下箭头>左箭头>右箭头。

##### （5）相邻求同与相邻求异

一组图形中，每相邻的两幅图进行两两比较，有相同或不同的元素。

**例题1（2014河南）**

**解析**：图1和图2中对角的两个三角形发生了互换，其他不变；图2和图3依然是对角的两个三角形发生了互换。

**例题5（2017联考）**

**解析**：两两比较，每相邻的两幅图之间都有一个图形相同。

##### （6）拉伸与替换

**例题1**

**解析**：第一行正方形经过上下左右拉伸变成了大正方形，第二行圆经过上下拉伸变成了长椭圆，第三行三角形经过左右拉伸应该变为C选项。

### 二、重构类图形推理

#### 1. 空间重构

空间重构图形推理，也就是常讲的折纸盒问题，是国考和省考的每年必考题型。

##### 三种常考立体图形性质

###### ① 正四面体

**性质一**：在正四面体的展开图中，相邻的成180度的线在折成立体图形时可以折在一起。

**性质二**：有两种平面展开图形。

###### ② 正方体

**性质一（重要）**：在正方形的平面展开图中，相邻的成90度的线在折成立体图形时可以折在一起。

**性质二**：相对面（对立面）在展开图中：
- 间隔一个面的两个面是相对面
- "Z"字两端的两个面是相对面

**性质三**：相邻面在折成立体图形后，相邻关系保持不变。

###### ③ 正八面体

**性质**：在正八面体的展开图中，相邻的成120度的线在折成立体图形时可以折在一起。

---

#### 2. 空间重构解题方法

##### （1）相对面法

利用相对面在立体图形中不能同时出现的原理排除选项。

**相对面判定方法**：
- 间隔一个面的两个面是相对面
- "Z"字两端的两个面是相对面

##### （2）相邻面法

利用相邻面在折成立体图形后相邻关系保持不变的原理判断选项。

**时针法**：在相邻面上画时针，判断时针方向是否改变。

##### （3）箭头法

在相邻面上画箭头，判断箭头指向是否改变。

---

#### 3. 空间重构常见题型

| 题型 | 说明 |
|------|------|
| **折纸盒** | 给出平面展开图，判断折成的立体图形 |
| **拆纸盒** | 给出立体图形，判断平面展开图 |
| **截面图** | 判断立体图形的截面形状 |
| **三视图** | 判断立体图形的主视图、俯视图、左视图 |
| **立体拼接** | 判断立体图形的拼接方式 |

#### 4. 平面重构

平面重构是指将平面图形按照一定规则重新组合的题型。

##### 解题方法

1. **转动**：图形可以旋转，但不能翻转
2. **拼接**：图形之间可以拼接，但不能重叠
3. **重组**：将图形拆分后重新组合

---

> 💡 **解题总结**：
> - **样式遍历**：缺谁补谁，注意横行、对应、补齐三种情况
> - **样式运算**：掌握去同存异、去异存同、黑白叠加等运算规则

> - **平面重构**：注意图形可以转动但不能翻转

## 类比推理-概念与映射关系

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第83-95页

---

### 一、类比推理概述

#### 1. 大纲分析

给出一组相关的词，要求通过观察分析，在备选答案中找出一组与之在逻辑关系上最为贴近或相似的词。

#### 2. 题型特点

类比推理是以词语为载体，要求同学对概念之间的逻辑关系进行判断、推理。总体来说题型比较简单，但容易让同学麻痹大意，造成不必要的丢分。

#### 3. 出题形式

| 形式 | 说明 | 示例 |
|------|------|------|
| **二词推理** | 题干由两个词组成 | 螺丝：螺帽 |
| **三词推理** | 题干由三个词组成 | 闪电战：战术：突袭 |
| **四词推理** | 括号填入两个词 | 净水器对于（）相当于（）对于汽缸 |

---

### 二、外延概念关系

概念外延指的是词语本身所包含的范围，研究的是集合关系。分为五种：全同关系、交叉关系、包含关系、并列关系与全异关系。

#### 1. 全同关系

全同关系指的是一组词的含义完全相同，只是表达方式不同。

##### 常见类型

| 类型 | 示例 |
|------|------|
| **概念与含义** | 四季与春夏秋冬，八卦与乾坤坎离震巽艮兑 |
| **古称与今称** | 汝和你，芙和荷花 |
| **中文与外文** | 话筒和麦克风，再见和沙扬娜拉 |
| **自称与他称** | 家父与令尊 |
| **雅称与俗称** | 解雇和炒鱿鱼 |

##### 例题解析

**例题1（2006国考）**

> 麦克风：话筒
> A.巧克力：糖果 B.炒鱿鱼：解雇 C.引擎：发动机 D.买单：结账

**解析**：此题考查全同关系，麦克风和话筒的含义完全相同，区别在于中外，选择C选项。

**例题3（2017联考）**

> 鸿雁：笺札：信
> A.月老：红娘：媒人 B.乾坤：天地：宇宙

**解析**：鸿雁、笺札和书信为全同关系。A选项月老和红娘都与媒人是全同关系。

---

#### 2. 交叉关系

两个集合之间存在交叉的关系，即有些A是B，有些A不是B。

##### 判断技巧

可以用"有的A是B，有的A不是B"来验证。

##### 例题解析

**例题1（2007江苏）**

> 运动员：大学生
> A.植物：种植 B.专家：青年 C.四季：春天 D.纸张：书法

**解析**：考查交叉关系，只有B符合。有的运动员是大学生，有的专家是青年。

**例题5（2018联考）**

> 团扇：羽毛扇：舞蹈扇
> A.宣纸：餐巾纸：铜版纸 B.圈椅：实木椅：办公椅

**解析**：题干中的三种扇子为交叉关系，分别从形状、材质、功能命名。B选项符合。

---

#### 3. 包含关系

包含关系分为**种属**和**组成**两种形式。

##### 区分技巧

利用"小是大"来造句判断：
- "女人是人" → 种属关系（通顺）
- "手是人" → 组成关系（病句）

##### 种属关系示例

- 银杉与树木（银杉是树木的一种）
- 进士与状元（状元是进士的一种）

##### 组成关系示例

- 骨骼与人体（骨骼是人体的组成部分）
- 笔画与汉字（笔画是汉字的组成部分）

##### 例题解析

**例题3（2018联考）**

> 进士：状元
> A.河水：海水 B.银河：天文 C.学位：博士 D.宪法：民法

**解析**：状元与进士属于种属关系。博士是学位的一种，选择C选项。

---

#### 4. 并列关系

当两个集合互不相同，且互不交叉的时候，为并列关系。分为**矛盾关系**和**反对关系**。

##### 矛盾关系 vs 反对关系

| 类型 | 定义 | 示例 |
|------|------|------|
| **矛盾关系** | 非此即彼，两者相加等于全集 | 生与死、男人与女人 |
| **反对关系** | 不满足非此即彼，允许存在第三者 | 黑与白、上午与下午 |

##### 例题解析

**例题1（2006广东）**

> 白天：黑夜
> A.男人：女人 B.高山：大海 C.白色：黑色 D.老人：小孩

**解析**：此题考查矛盾关系，符合的只有A选项。白天和黑夜非此即彼，男人和女人也是。

**例题4（2018山东）**

> 有形损耗：无形损耗
> A.中国哲学：西方哲学 B.蒸馏酒：葡萄酒 C.急性中毒：慢性中毒

**解析**：有形损耗与无形损耗属于矛盾关系。C选项急性中毒与慢性中毒也是矛盾关系。

---

#### 5. 全异关系

当两个集合完全没有任何逻辑联系的时候，为全异关系。

##### 例题解析

**例题（2010江苏）**

> 实数：木耳
> A.长江：河流 B.硕士：法官 C.黄山：牛顿 D.燕雀：鸿

**解析**：实数和木耳之间完全没有联系，C选项黄山与牛顿也是全异关系。

---

### 三、外延关系总结

```
外延概念关系
├── 全同关系：A = B（含义完全相同）
├── 交叉关系：有的A是B，有的A不是B
├── 包含关系
│   ├── 种属关系：A是B的一种
│   └── 组成关系：A是B的组成部分
├── 并列关系
│   ├── 矛盾关系：非此即彼
│   └── 反对关系：允许存在第三者
└── 全异关系：完全无联系
```

### 四、内涵映射关系

内涵是事物的特有属性的反映，常见的内涵映射关系主要有：条件关系、属性关系及对应关系。

#### 1. 条件关系

条件关系指事物与事物之间的充分条件性与必要条件性。

##### 记忆口诀

| 条件类型 | 口诀 | 位置 |
|----------|------|------|
| **充分条件** | 有他就行放前面 | A→B（A是B的充分条件） |
| **必要条件** | 没他不行放后面 | B→A（A是B的必要条件） |

##### 例题解析

**例题1（2006江苏）**

> 下雨：地面湿
> A.夜晚：星星 B.烈日：气温高 C.苹果：果树 D.放假：补功课

**解析**：下雨能推出地面湿，即下雨是地面湿的充分条件，符合条件的只有B选项。

**例题2（2014河北）**

> 氧气：燃烧
> A.吃饭：健康 B.打雷：下雨 C.水涨：船高 D.团员：党员

**解析**：氧气是燃烧的必要条件。吃饭是健康的必要条件，选择A选项。

---

#### 2. 属性关系

属性关系指事物之间关系的必然性与或然性。

| 类型 | 定义 | 示例 |
|------|------|------|
| **必然性** | 必然对应的性质 | 盐与咸，雪与白 |
| **或然性** | 非必然性质 | 花与红色，叶与绿色 |

##### 例题解析

**例题1（2007国考）**

> 盐：咸
> A.花：香 B.丝：棉 C.光：亮 D.墨：臭

**解析**：考查必然关系，盐必然是咸的，光必然是亮的，选择C选项。

**例题4（2018国考）**

> 花椒：麻
> A.月亮：圆 B.水泥：硬 C.饮料：冷 D.火焰：热

**解析**：花椒必然是麻的，火焰必然是热的，选择D选项。

---

#### 3. 对应关系

对应关系指事物之间的匹配关系，常见的有：
- 人物与作品
- 事件与时间
- 地点与事物
- 功能对应

![映射关系示意图](判断推理知识库-备考手册.assets/映射关系示意图.svg)

---

> 💡 **解题技巧**：
> 1. 先判断外延关系（全同、交叉、包含、并列、全异）
> 2. 再判断内涵关系（条件、属性、对应）
> 3. 使用"小是大"造句法判断种属与组成关系
> 4. 注意区分矛盾关系与反对关系

## 类比推理-语法语义与创新

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第96-99页

---

### 一、词句语法关系

在类比推理的言语关系考点中经常会涉及语法关系，主要是涉及一个句子主干部分的不同组合。

#### 句子结构

一个完整的句子结构是：**（定语）主语[状语]谓语（定语）宾语**

不同成分的不同组合构成了不同的语法关系，常见的主要有主谓关系、动宾关系、并列结构以及修饰关系四种。

---

#### 1. 主谓关系

主谓关系是指题干中出现的两个词语连起来可以充当一个句子的主语和谓语，主语常见的是名词，谓语一般是动词或形容词。

##### 示例

- 轮船：起航
- 宝石：发光
- 黔驴技穷
- 八仙过海
- 木已成舟

##### 例题解析

**例题1（2008国考）**

> 法律：约束
> A.新闻：广播 B.政策：规范 C.历史：借鉴 D.制度：学问

**解析**：法律约束人的行为，政策规范企业的行为，是主谓关系，选B。

**例题3（2014青海）**

> 居住：居民
> A.继承：继承人 B.吝啬：守财奴

**解析**：居民居住，主谓关系，前一词词性为动词，后一词词性为名词。A项中继承人继承，主谓关系，词性也相符。

---

#### 2. 动宾关系

动宾关系是指题干中出现的两词语连起来可以充当一个句子的谓语和宾语，一般是"动词+名词"的组合。

##### 示例

- 讨论：问题
- 风卷：残云
- 明察秋毫
- 巧夺天工

![类比推理场景示例](判断推理知识库-备考手册.assets/类比推理场景示例.svg)

##### 例题解析

**例题1（2010江苏）**

> 结构：剖析
> A.分享：快乐 B.资源：利用 C.景色：秀美 D.交通：航运

**解析**："剖析结构"是动宾关系，"利用资源"与题干一致，选B。

**例题3（2011浙江）**

> 决策：执行
> A.组织：监督 B.计划：实施 C.总结：改进 D.合同：制造

**解析**：执行决策，决策为宾语，执行为谓语，考察动宾关系，与题干相同结构的为B选项。

---

#### 3. 并列关系（语法）

在语句语法关系里面的并列，指由两个词性相同的实词并列组成。

##### 示例

- 嫦娥奔月与后羿射日
- 学习与掌握
- 天南地北
- 甜言蜜语

##### 例题解析

**例题1（2007江苏）**

> 万水：千山
> A.四通：八达 B.乱七八糟 C.五湖：四海 D.七上：八下

**解析**：题干两词是并列关系，且每个词都是偏正结构。"五湖"和"四海"彼此并列，选择C。

**例题2（2009山东）**

> 丰功：伟绩
> A.维和：行动 B.风餐：露宿 C.文化：传播 D.风卷：残云

**解析**：丰功伟绩是并列结构的成语，且丰功和伟绩都属于偏正关系；风餐露宿也是并列结构的成语，且风餐和露宿也都是偏正关系。

---

#### 4. 修饰关系

修饰关系是指题干中出现的两个词语中一个是中心词语，另一个作为修饰成分修饰中心词语，所以修饰关系又称为偏正关系。

##### 常见形式

1. 两个词之间的关系：美丽与姑娘，聪明与一休
2. 同一个词前后的偏正：春花秋月，无边落木
3. 形容词或名词修饰名词，中间可以用"的"连接：富强的国家
4. 副词修饰动词，中间可以用"地"连接：轻易地获取，猛然地进攻

##### 例题解析

**例题1（2012安徽）**

> 谬误：语法
> A.木头：煤炭 B.俗气：文章 C.馒头：面粉 D.快乐：高兴

**解析**："谬误的语法"，"俗气的文章"，与题干一致，选B。

**例题2（2010吉林）**

> 窗户：玻璃
> A.衣服：纽扣 B.盆架：脸盆 C.戒指：宝石 D.照片：相册

**解析**：名词修饰名词，玻璃可以作为窗户的定语，构成偏正短语"玻璃窗户"，宝石可以作为戒指的定语，构成偏正短语"宝石戒指"。

---

### 二、语义关系

语义关系指的是词语之间含义的关系，包括同义词与近义词、反义词与相对义、象征义与比喻义三种。

#### 1. 同义词与近义词

指的是词汇意义相同或相近的词语。

##### 例题解析

**例题1（2013浙江）**

> 本分：职责
> A.羁绊：障碍 B.奇葩：宝库 C.蓝图：想象 D.傲慢：偏见

**解析**：本分和职责为近义词，只有A选项是同义词。

**例题5（2018国考）**

> 羔羊跪乳：乌鸦反哺
> A.昙花一现：惊鸿一瞥 B.魂不附体：失魂落魄

**解析**：考查近义词，题干两个词都是感恩父母的意思。B都是极度惊慌忧虑，近义词。

---

#### 2. 反义词与相对义

指的是词语之间的意思相反或者相对。

##### 例题解析

**例题1（2011国考）**

> 亦步亦趋：主见
> A.兴高采烈：恐惧 B.优柔寡断：果断 C.鼠目寸光：眼力 D.孤陋寡闻：胆识

**解析**：亦步亦趋是没有主见，优柔寡断是不果断，选B。

**例题4（2018广州）**

> 拐弯抹角：（）与（）富有在内在逻辑关系上最为相似。
> A.直接，家徒四壁 B.委婉，穷困潦倒 C.直白，家财万贯 D.清楚，富可敌国

**解析**：A选项前后都是反义词，当选。

---

#### 3. 象征义与比喻义

象征义指的是，汉语一些词语因文化传统和文化心理引发的联想而产生了象征意义。

##### 例题解析

**例题1（2011国考）**

> （）对于吉祥相当于狼烟对于（）
> A.和平战争 B.麒麟信号 C.盛世烽火 D.凤凰入侵

**解析**：凤凰象征吉祥，狼烟象征入侵，选择D选项。

**例题2（2008山西）**

> 明镜：公正
> A. 镜子：自不量力 B.麒麟：祥瑞 C.木马：病毒 D.貔貅：军队

**解析**：明镜象征公正，麒麟象征祥瑞，选择B选项。

---

### 三、创新类比

近年来，在传统的类比推理题型之外，还有五种创新题型：

#### 1. 字音类比

考查一个字的读音，分为声母和韵母。注意字音题目一般词汇都是非常规词语。

##### 例题解析

**例题1（2010江苏）**

> 徘徊：荡漾
> A.八哥：混淆 B.苍茫：蓓蕾 C.循环：乾坤 D.空响：浪漫

**解析**：两组词的读音为páihuái，dàngyàng，每组词两个字之间的韵母都相同，只有B选项符合条件。

---

#### 2. 字形类比

考查汉字的字形结构，如：
- 上下结构、左右结构、包围结构
- 偏旁部首
- 笔画数

---

#### 3. 字义类比

考查汉字的字义，包括：
- 本义与引申义
- 多义词的不同义项

---

#### 4. 感情色彩

考查词语的感情色彩：
- 褒义词
- 贬义词
- 中性词

---

#### 5. 字符类比

考查字符（字母、数字等）之间的关系。

---

> 💡 **解题技巧**：
> 1. 先判断外延关系（全同、交叉、包含、并列、全异）
> 2. 再判断内涵关系（条件、属性、对应）
> 3. 语法关系通过造句子来判断
> 4. 语义关系注意近义词、反义词、象征义的区别
> 5. 创新类比需要多积累常见字音、字形知识

## 逻辑判断-基本逻辑原理

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第100-114页

---

### 一、逻辑判断概述

#### 1. 大纲分析

每道题给出一段陈述，这段陈述被假设是正确的，不容置疑的。要求报考者根据这段陈述，运用一定的逻辑推论，选择一个最恰当的答案。

#### 2. 核心要点

| 要点 | 说明 |
|------|------|
| **前提不容置疑** | 前提属于非黑即白，关注细节思维不发散 |
| **必然性推理答案唯一** | 不要带入常识，纯靠逻辑去做 |
| **论证类题目用朴素思维** | 先用生活中朴素的逻辑思维做排除 |
| **答案不唯一时选最优** | 考虑优先原则，选相对好的答案 |

#### 3. 常见考点分类

| 分类 | 内容 |
|------|------|
| **基本逻辑原理** | 单句翻译、复句翻译、易错关联词、矛盾关系、反对关系、推出关系、等价关系、模态命题 |
| **推理类题型** | 翻译推理、真假推理、分析推理、归纳推理、解释推理、数学推理、类推比较 |
| **论证类题型** | 一般类论点加强型、一般类论点削弱型、因果类论点加强型、因果类论点削弱型 |

---

### 二、五个复句翻译

复句翻译是将长复杂的文字语言转化为箭头语言的过程。

#### （1）充分条件

**定义**：如果A能推出B，那么A就是B的充分条件。

**翻译**：A→B

**记忆口诀**：有他就行放前面

##### 常见关联词

| 关联词 | 翻译 |
|--------|------|
| 如果A，那么B | A→B |
| 若A，那么B | A→B |
| 所有A都是B | A→B |
| 只要A，就B | A→B |
| 凡是A，都B | A→B |

---

#### （2）必要条件

**常见关联词**

| 关联词 | 翻译 |
|--------|------|
| 只有B，才A | A→B |
| B是A的必要条件 | A→B |
| B是A的前提 | A→B |
| A的基础是B | A→B |
| 为了A，一定B | A→B |
| A离不开B | A→B |

**记忆口诀**：没他不行放后面

**万能方法**：判断出谁是必不可少的条件，把必要条件放后面。

**示例**："人类为了能生存，一定要有氧气" → 氧气必不可少 → 氧气放后面 → 生存→氧气

---

#### （3）逆否命题

**形式**：A→B 等价于 -B→-A

**四大要点**：
1. 充分条件：有他就行放前面
2. 必要条件：没他不行放后面
3. 肯前必肯后
4. 否后必否前

**注意**：否前肯后得不出任何确定性结论

**例题1（2018上海）**

> 领导干部如果没有底线思维，就不能做到严格自律。而只有不忘初心，才能始终保持底线思维。也只有始终坚守理想信念，才能不忘初心。

**解析**：翻译得到：自律→底线思维→不忘初心→理想信念。B选项正确。

**例题3（2018浙江）**

> 如果不学习电吉他，阿健就当不了乐队主唱；如果他想玩乐器，他会选择学习电吉他；如果他不玩乐器，他就当主唱。

**解析**：主唱→电吉他。玩乐器→电吉他。不玩乐器→主唱→电吉他。发现不管他是否玩乐器，都会选择学习电吉他。

---

#### （4）联言命题

**形式**：A且B

**性质**：一假即假，同真才真

##### 常见关联词

| 关联词 | 翻译 |
|--------|------|
| 既A又B | A且B |
| 不但A而且B | A且B |
| 不仅A还B | A且B |
| 虽然A但是B | A且B |
| A，B | A且B |
| 同时A，B | A且B |

**例题（2018广州）**

> 只有具有良好的逻辑思维能力并且具有物理学专业背景的人，才能胜任这个岗位。

**解析**：翻译得到：胜任→逻辑且物理。B选项"从未学习过物理学知识的小李胜任了这个岗位"不可能为真。

---

#### （5）选言命题

**形式**：A或B

**性质**：一真即真，两假才假

**推论**：如果"A或B"正确，且A错误，则B必然正确。

**例题（2018广东）**

> 某围棋队有选手会在比赛时喝茶，他们或者喝红茶，或者喝绿茶。

**解析**：喝茶→红茶或绿茶。Ⅱ正确，队员喝茶时一定是红茶或绿茶，不可能是黑茶。

---

### 三、八个单句翻译

| 序号 | 命题 | 等价翻译 |
|------|------|----------|
| 1 | 所有的A都是B | A→B |
| 2 | 没有A不是B | A→B |
| 3 | 所有的A都不是B | A→-B 也等价于 B→-A |
| 4 | 没有A是B | A→-B |
| 5 | 不是A的都是B | -A→B |
| 6 | 不是A的都不是B | -A→-B |
| 7 | A和B至少选一个 | A或B |
| 8 | A和B至多选一 | -A或-B |

**特别注意**：
- "不都"等价于"并非所有"，也就是"有的不"的意思
- "都不"是"所有不"的意思
- 两者意思截然不同，切忌混为一谈

---

### 四、七个易错关联词

#### （1）除非A，否则B

**翻译**：-A→B

**方法**：后面的非A不要动，B没有否定词就直接"非A→B"

#### （2）除非A，否则不B

**翻译**：-A→-B

#### （3）当且仅当A时，B

**翻译**：A→B 且 B→A（充分必要条件）

#### （4）因为A，所以B

**注意**：因果关系和推出关系是完全不同的逻辑关系！

| 情况 | 翻译 |
|------|------|
| A的发生必然引起B的反应 | A→B |
| A是引起B不可或缺的原因 | B→A |

#### （5）要么A，要么B

**性质**：不相容选言命题，A和B不可同真，也不可同假，有且只有一个是真的。

#### （6）有的A是B

**注意**：在逻辑中涵盖三种情况：
1. 1个A是B
2. 部分A是B
3. 所有的A都是B

#### （7）不都与都不

- "不都" = "并非所有" = "有的不"
- "都不" = "所有不"

**例题1（2014联考）**

> 老王对老李说："除非你在今天之内按照合同要求支付货款，否则我们法庭上见。"

**解析**：翻译得到：-支付货款→法庭见。B选项犯了否前推否后的错误。

---

### 五、五对矛盾关系

#### 矛盾关系的性质

| 性质 | 说明 |
|------|------|
| **性质一** | 互为矛盾关系的双方主体必须一致 |
| **性质二** | A+非A=全世界，不存在第三种情况 |
| **性质三** | 矛盾关系的双方，必有一真必有一假 |

#### 五对矛盾关系

| 序号 | 矛盾对 | 说明 |
|------|--------|------|
| 1 | A与非A | 单论点与单论点的否定 |
| 2 | 所有A都是B 与 有的A不是B | 全称肯定与特称否定 |
| 3 | 所有A都不是B 与 有的A是B | 全称否定与特称肯定 |
| 4 | A且B 与 -A或-B | 联言与选言的否定 |
| 5 | A或B 与 -A且-B | 选言与联言的否定 |

**例题（2015联考）**

> 甲说："犯罪嫌疑人向东逃跑了。"
> 乙说："犯罪嫌疑人没有向东逃跑。"
> 丙说："犯罪嫌疑人没有向南逃跑。"

**解析**：甲和乙的说法是矛盾关系，必有一真一假。

---

### 六、两大反对关系

#### 1. 上反对关系

**关系**：所有A都是B 与 所有A都不是B

**性质**：不能同真，可以同假

#### 2. 下反对关系

**关系**：有的A是B 与 有的A不是B

**性质**：可以同真，不能同假

---

### 七、推出关系

#### 全称与特称的推出关系

| 全称命题 | 推出 | 特称命题 |
|----------|------|----------|
| 所有A都是B | → | 有的A是B |
| 所有A都不是B | → | 有的A不是B |

---

### 八、等价关系

#### 常见等价关系

| 原命题 | 等价命题 |
|--------|----------|
| A→B | -B→-A（逆否命题） |
| 并非（A且B） | -A或-B |
| 并非（A或B） | -A且-B |
| 有的A是B | 有的B是A |
| 所有A都不是B | 所有B都不是A |

---

### 九、模态命题

#### 模态命题的矛盾关系

| 模态命题 | 矛盾命题 |
|----------|----------|
| 必然P | 可能非P |
| 可能P | 必然非P |
| 必然非P | 可能P |
| 可能非P | 必然P |

#### 模态命题的推出关系

| 模态 | 推出 |
|------|------|
| 必然P | 可能P |
| 必然非P | 可能非P |

---

> 💡 **解题技巧**：
> 1. 熟练掌握五个复句翻译（充分、必要、逆否、联言、选言）
> 2. 牢记八个单句翻译的等价关系
> 3. 注意区分矛盾关系和反对关系
> 4. 掌握逆否命题的等价转换
> 5. 遇到"有的"要想到三种情况

## 逻辑判断-推理题型

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第115-128页

---

### 一、推理类基本题型概述

推理类基本题型考查的核心是基于逻辑基本原理的七种题型：

| 题型 | 说明 |
|------|------|
| **翻译推理** | 将文字语言转化为箭头语言，利用逆否命题解题 |
| **真假推理** | 找到矛盾关系或反对关系，判断真假 |
| **分析推理** | 根据条件进行逻辑分析，推出结论 |
| **归纳推理** | 从个别到一般的推理 |
| **解释推理** | 解释题干中的现象或矛盾 |
| **数学推理** | 运用数学知识进行逻辑推理 |
| **相似推理** | 找出与题干逻辑结构相似的选项 |

---

### 二、翻译推理

#### 1. 解题步骤

1. 将文字语言转化为箭头语言
2. 找到充分条件和必要条件
3. 画出箭头（充分条件在前，必要条件在后）
4. 充分利用逆否命题解题

#### 2. 常用等价关系

| 原命题 | 等价命题 |
|--------|----------|
| A→B | -B→-A（逆否命题） |
| A→B | -A或B |
| 并非（A且B） | -A或-B |
| 并非（A或B） | -A且-B |

#### 3. 例题解析

**例题1（2016国考）**

> 某大型晚会的导演组在对节目进行终审时有六个节目尚未确定是否通过，这六个节目分别是歌曲A、歌曲B、相声C、相声D、舞蹈E和魔术F。综合考虑各种因素，导演组确定了如下方案：
> （1）歌曲A和歌曲B至少要上个；
> （2）如果相声C不能通过或相声D不能通过，则歌曲A也不能通过；
> （3）如果相声C不能通过，那么魔术F也不能通过；
> （4）只有舞蹈E通过，歌曲B才能通过。
> 导演组最终确定舞蹈E不能通过。

**解析**：
- （1）A或B
- （2）-C或-D→-A，等价于：A→C且D
- （3）-C→-F，等价于：F→C
- （4）B→E

根据条件（4），-E→-B；根据条件（1），-B→A；根据条件（2），A→C且D。

得到：-E→-B→A→C且D，可以确定A-E五个节目的情况，但是不知道节目F的情况。

**例题2（2018联考）**

> 一个人如果是智者，那么他一定是一位谦虚的人；而一个人只有认识到自己的不足，他才会谦虚。但是，如果一个人听不进别人的意见，那么他就不会认识到自己的不足。

**解析**：翻译得到：智者→谦虚→认识不足→听得进意见。B选项是逆否命题，正确。

---

### 三、真假推理

#### 1. 解题步骤

1. 找到矛盾关系或反对关系
2. 利用矛盾关系（必有一真一假）或反对关系（必有一假/必有一真）判断
3. 推出其他命题的真假

#### 2. 矛盾关系与反对关系

| 关系类型 | 形式 | 性质 |
|----------|------|------|
| **矛盾关系** | A与非A | 必有一真一假 |
| **上反对关系** | 所有A都是B 与 所有A都不是B | 必有一假，可以同假 |
| **下反对关系** | 有的A是B 与 有的A不是B | 必有一真，可以同真 |

#### 3. 例题解析

**例题（2018广州）**

> 下面是某冬日我国北方某些城市的天气情况：
> （1）有些城市有降雪；
> （2）有些城市没有降雪；
> （3）北京和邯郸没有降雪。
> 如果三个断定中只有一个为真，那么以下选项中哪个断定一定为真？

**解析**：①②两个"有的"必有一真，又因为只有一个真的，所以③错①对②错，那么所有城市都下雪。

---

### 四、分析推理

#### 1. 解题步骤

1. 根据已知条件进行逻辑分析
2. 利用排除法、代入法或图表法
3. 推出确定性的结论

#### 2. 例题解析

**例题（2018联考）**

> 某单位要从甲、乙、丙、丁、戊、己6名工作人员中选派3名参加省职业技能大赛。有4位评委分别提出了自己的意见：
> （1）甲、丙二人中至少选一人；
> （2）乙、戊二人中至少选一人；
> （3）乙、丙二人中至多选一人；
> （4）甲、丁二人中至多选一人。
> 后来得知，戊因病不能参赛，并且上述4位评委的意见都得到了尊重。

**解析**：
- （1）甲或丙
- （2）乙或戊
- （3）-乙或-丙
- （4）-甲或-丁

利用-戊这个条件，得到：-戊→乙→-丙→甲→-丁，不选丙丁戊，那么就只能选择甲乙己。

---

### 五、归纳推理

#### 1. 解题原则

| 原则 | 说明 |
|------|------|
| **话题一致** | 选项与题干话题必须一致 |
| **从弱原则** | 优选可能性选项，避免绝对化 |
| **整体优先** | 优先选择涵盖整体的选项 |
| **敏感词汇** | 注意"所有"、"都"、"一定"等绝对化表述 |

#### 2. 常见错误选项

- 无中生有
- 夸大其词
- 过度推断
- 混淆概念

---

### 六、解释推理

#### 1. 解题步骤

1. 找到题干中的矛盾或现象
2. 分析各选项是否能解释该矛盾
3. 选择最能合理解释的选项

#### 2. 例题解析

**例题**

> 在某次考试中，有3个要求英语成绩在90分以上，有3个要求数学成绩在90分以上，但实际上只有2人同时满足两个条件。以下哪项最能解释这一现象？

**解析**：需要解释为什么要求的人数和实际满足的人数不一致，可能是因为有人同时被两个条件计算了。

---

### 七、数学推理

#### 1. 常见题型

| 题型 | 说明 |
|------|------|
| **比例问题** | 根据比例关系进行推理 |
| **集合问题** | 利用容斥原理解题 |
| **最值问题** | 求最大值或最小值 |
| **排列组合** | 运用排列组合知识 |

#### 2. 解题技巧

- 画图辅助理解
- 利用方程求解
- 代入验证

---

### 八、相似推理

#### 1. 解题步骤

1. 分析题干的逻辑结构
2. 找出与题干逻辑结构相似的选项
3. 注意排除干扰选项

#### 2. 常见逻辑结构

| 结构 | 说明 |
|------|------|
| **A→B** | 充分条件推理 |
| **只有B，才A** | 必要条件推理 |
| **A且B** | 联言推理 |
| **A或B** | 选言推理 |

---

> 💡 **解题技巧**：
> 1. 翻译推理：熟练掌握箭头语言和逆否命题
> 2. 真假推理：先找矛盾关系，再找反对关系
> 3. 分析推理：利用排除法和图表法
> 4. 归纳推理：注意从弱原则，避免绝对化
> 5. 所有题型都要注意话题一致原则

## 逻辑判断-加强与削弱论证

> 📚 来源：《全新【公考状元笔记】第二讲 判断推理篇》第129-145页

---

### 一、论证三要素

论证由论点、论据和论证方式三个要素组成：

| 要素 | 定义 | 说明 |
|------|------|------|
| **论点** | 论证要确定其真实性的判断 | 回答"论证什么" |
| **论据** | 证明论点真实性判断的根据 | 理论论据或事实论据 |
| **论证方式** | 论证过程中的判断和推理形式 | 回答"怎样论证" |

#### 三种常见论证方式

| 论证方式 | 定义 | 示例 |
|----------|------|------|
| **演绎** | 从多到少，从群体特征推出个体特征 | "中国人都吃苦耐劳，推出鲁迅先生吃苦耐劳" |
| **归纳** | 从少到多，从个体特征推出群体特征 | "长沙女人很贤惠，推出湖南女人很贤惠" |
| **类比** | 你有我有大家有 | "你吃蘑菇了，他吃蘑菇了，大家都吃蘑菇了" |

![论证关系图](判断推理知识库-备考手册.assets/论证关系图.svg)

---

### 二、论点分类与定位

#### 论点分类

| 类型 | 定义 | 示例 |
|------|------|------|
| **一般类论点** | A是什么或A怎么样 | "在深海中，确实有不为人知的海底巨型生物" |
| **因果类论点** | A导致B | "就寝时关闭门窗将会降低睡眠质量" |

#### 定位论点的三个原则

1. **引导词原则**：
   - 表观点：认为、以为、观点是
   - 表结果：因此、所以
   - 表结论：表明、说明、结果是
   - 表建议：建议、忠告

2. **首尾句原则**：论点出现在尾句的情况比较多

3. **结合设问方式**：题干涉及多个论点时要特别注意

---

### 三、加强型论证

#### 加强方式总览

| 加强方式 | 适用范围 | 核心要点 |
|----------|----------|----------|
| **补充前提** | 一般类+因果类 | 必要条件，否定后结论不成立 |
| **加强论点** | 一般类+因果类 | 重复、强调、解释论点 |
| **加强论据** | 一般类+因果类 | 加强现有论据或增加新论据 |
| **搭桥加强** | 一般类+因果类 | 在论据与论点间建立联系 |
| **对比实验** | 因果类特有 | 有因有果 vs 无因无果 |

#### 1. 补充前提

补充前提是补充一个**必要条件**，即如果该条件不成立，结论就不成立。

**解题方法**：将选项否定后检验结论是否仍成立

**例题1**（2013国考）：
> 科研人员的判断还需基于哪一前提？
> 论点：利用内生菌消除塑料垃圾威胁
> 正确选项C：目前绝大多数塑料垃圾都属于普遍的聚氨酯塑料

**例题2**（2017国考）：
> 论点：火星早期覆盖着冰原
> 正确选项C：沸石、硫化物和黏土仅在冰川下火山活动后才会产生

#### 2. 加强论点

通过重复、强调或解释论点来加强。

**例题**（2007湖南）：
> 论点：长期饮用超纯净的水不利于健康
> 正确选项B：只有未经处理的自然界的水，才符合人体健康的需要

#### 3. 加强论据

| 方式 | 说明 |
|------|------|
| 加强现有论据 | 证明原有论据更可靠 |
| 增加新论据 | 包括举例论证 |

**例题**（2017联考）：
> 论点：睡眠干预可减少社会偏见与歧视
> 正确选项C：有身高歧视、相貌歧视的人经过睡眠干预后，歧视程度明显降低（举例论证）

#### 4. 搭桥加强

在论据与论点之间（或原因与结果之间）建立桥梁，解释说明两者联系。

**例题**（2014国考）：
> 论点：海水升温导致鱼类生存挑战
> 论据：防冻蛋白使鱼类得以存活
> 正确选项C：南极海水含氧量随气温上升而下降，缺氧导致防冻蛋白变性...缩短鱼的寿命

#### 5. 对比实验

| 组别 | 情况 |
|------|------|
| 实验组 | 有原因，有结果 |
| 对照组 | 无原因，无结果 |

**前提**：两组除原因外其他条件一致

**例题**（2018联考）：
> 论点：基因疗法为脊髓性肌萎缩症治疗带来突破性进展
> 正确选项D：对照组的所有患者都没有恢复运动机能

![对比实验示意图](判断推理知识库-备考手册.assets/对比实验示意图.svg)

#### 加强型论证力度对比

![加强削弱逻辑链](判断推理知识库-备考手册.assets/加强削弱逻辑链.svg)

1. **补充前提和对比实验**出现可直接当选
2. **搭桥加强**力度 > 加强论点和加强论据
3. 加强论点和加强论据之间需具体分析

---

### 四、削弱型论证

#### 削弱方式总览

| 削弱方式 | 适用范围 | 核心要点 |
|----------|----------|----------|
| **否定前提** | 一般类+因果类 | 否定必要条件 |
| **削弱论点** | 一般类+因果类 | 直接否定论点 |
| **削弱论据** | 一般类+因果类 | 否定论据或举反例 |
| **拆桥** | 一般类+因果类 | 切断论据与论点联系 |
| **因果倒置** | 因果类特有 | B才是A的原因 |
| **有因无果** | 因果类特有 | 有A但没B |
| **另有他因** | 因果类特有 | C才是B的真正原因 |
| **无因有果** | 因果类特有 | 没A但有B |
| **对比实验** | 因果类特有 | 否定前提一致性 |

![削弱力度对比流程图](判断推理知识库-备考手册.assets/削弱力度对比流程图.svg)

#### 1. 否定前提

对论证成立的必要条件进行否定。

**例题**（2017联考）：
> 论断：通过下发宣传册教大家预防和治疗近视
> 隐含前提：近视可以进行自我预防和治疗
> 正确选项D：近视很难进行自我预防和治疗

#### 2. 削弱论点

直接否定题干的论点。

**例题**（2009安徽）：
> 论点：穿着纯棉织物要比使用化纤物更环保
> 正确选项D：棉花是使用农药最多的农作物，世界上的杀虫剂25%被用于棉花种植

#### 3. 削弱论据

| 方式 | 说明 |
|------|------|
| 直接否定论据 | 指出论据错误 |
| 增加反论据 | 举反例 |

**例题**（2010宁夏）：
> 论点：宇宙间基本粒子被发现得差不多了
> 正确选项C：新发现的基本粒子与"标准理论"做出的预测不相符

#### 4. 拆桥

切断论据与论点之间的联系。

**例题**（2017广东）：
> 论据：市场空缺大于求职人数
> 论点：大学生不存在就业难
> 正确选项B：劳动力市场最紧缺的岗位主要是适合高级技工的岗位

#### 5. 因果倒置

题干指出A是B的原因，削弱指出B才是A的原因。

**例题**（2015河南）：
> 题干：掌握两种语言→延缓痴呆
> 正确选项B：大脑认知功能好的人才会说双语，认知功能好可延缓痴呆

**例题**（2009浙江）：
> 题干：足球运动→增进身体健康
> 正确选项B：身体不太好的大学生一般不参加激烈的足球运动

#### 6. 有因无果

题干指出"A必然引起B"，削弱指出"有A但没B"。

**例题**（2004国考）：
> 题干：健壮体魄→足够钙质→奶制品
> 正确选项C：有的牧民有健壮的体魄，但没有充足的奶制品作为食物来源

#### 7. 另有他因

提出C才是B的真正原因，削弱A与B的因果关系。

**例题**（2014国考）：
> 论点：试管婴儿技术导致出生缺陷率高
> 正确选项D：试管婴儿的父母比自然受孕婴儿的父母年龄大很多，父母年龄越大，新生儿出生缺陷率越高

#### 8. 无因有果

题干指出"A必然引起B"，削弱指出"没A但有B"。

**例题**（2016联考）：
> 题干：导热性→大量原子
> 正确选项B：有的物质导热性不强，但是它的分子中包含了大量的原子

#### 9. 对比实验削弱

| 削弱角度 | 说明 |
|----------|------|
| 样本数量不足 | 样本太小无法代表整体 |
| 样本不正确 | 不具有代表性，以偏概全 |
| 前提不一致 | 两组除原因外其他条件不一致 |

**例题**（2018联考）：
> 论点：克隆动物的衰老过程正常
> 正确选项A：研究中对照组羊的年龄比实验组羊的年龄小

**例题**（2010宁夏）：
> 论点：闪婚是夫妻离婚的重要原因
> 正确选项B：到该市民政部门办理的协议离婚案件占该市离婚案件总量的70%（说明法院案件不具代表性）

---

### 五、加强与削弱对比总结

| 类型 | 方式 | 力度 |
|------|------|------|
| **加强** | 补充前提/对比实验 | 最强 |
| **加强** | 搭桥 | 较强 |
| **加强** | 加强论点/加强论据 | 需具体分析 |
| **削弱** | 否定前提/因果倒置 | 最强 |
| **削弱** | 拆桥/有因无果 | 较强 |
| **削弱** | 另有他因/无因有果 | 较弱 |

---

### 六、解题步骤

1. **找论点**：通过引导词、首尾句原则定位
2. **找论据**：识别支持论点的依据
3. **判断类型**：一般类还是因果类
4. **分析选项**：识别加强/削弱方式
5. **比较力度**：选择最能加强或削弱的选项

## 定义判断

### 一、定义判断概述

#### 大纲分析

定义判断主要考查运用给定标准定义进行判断的能力。每道题先给出一个概念，然后对该概念进行定义，要求根据给出的定义，从备选项中选出一个**最符合**或**最不符合**该定义的典型事件或行为。

**题型特点**：
- 定义判断就是举例论证：定义项是论点，解释是理论论证，选项是举例论证
- 只能用排除法，题干不能直接推出答案
- 考试一般10道题，用时控制在8分钟以内（每道约48秒）

#### 题型难点

1. **定义专业化**：题干越来越长，干扰寻找定义要点
2. **选项言语化**：设置迷惑选项
3. **提问形式易出错**：分肯定性判断（属于）和否定性判断（不属于）

#### 核心原则

- **题干为王**：定义本身不容置疑
- 认真审题，看清问"属于"还是"不属于"

### 二、提取信息要点（关键词法）

通过提取关键词化整为零，快速破解题干定义：

| 要素 | 定义 | 作用 |
|------|------|------|
| **主体** | 行为或事件的发动者、当事方 | 选项不符合主体要求可直接排除 |
| **客体** | 行为或事件的承受者、被指向者 | 某些定义必须针对特定对象 |
| **主观要素** | 行为者主观上的动机、意图、目的 | 判断主观动机是否符合 |
| **客观要素** | 客观上实施的行为、方式、程度、结果 | 判断客观行为是否符合 |



**例题1**（2009国考）：
> 产品召回主体为"生产商"——排除A、B（主体不合格）
> 行为方式："主动将产品都收回"——排除D（仅向提起诉讼的赔偿）
> 正确答案：C

**例题2**（2007国考）：
> 企业信息化主体为"企业"
> A选项主体为"学校"，不符合定义

**例题3**（2005国考）：
> 高峰体验关键词："追求自我实现"
> B选项观众看电视不属于追求自我实现，不符合

### 三、归纳关键信息

当题干核心成分多、不好区分时，用自己的语言概括定义主要特征，进行同义替换。

**例题1**（2014天津）：
> 霸王条款核心特征概括为"商家的不平等条款"
> D选项是消费者行为，明显不符合，当选

**例题2**（2017新疆）：
> 木椅子效应概括为：不舒服反而成绩好
> B选项每天步行上学（条件艰苦）但学得很好，符合

### 四、被定义项隐含要点

从定义名称本身寻找隐含信息，快速排除不符合选项。

**例题1**（2012甘肃）：
> "虚拟人力资源管理"——从名称可知与"人"有关
> B选项管的是广告，与人力无关，直接排除

**例题2**（2012甘肃）：
> "随意想象"——一定是想象
> B真实发生（非想象）、C做梦（非想象）、D回忆（非想象），排除后选A

**例题3**（2012国考）：
> "统计性歧视"——从整体出发歧视个体（从多到少的歧视）
> A从少到多，C科学预测无歧视，D从少到多，选B

**例题4**（2010国考）：
> "同类群体影响力"——必须有同类群体
> B选项没有同类群体，不符合

### 五、相似选项类聚

当题干复杂难懂时，从选项入手，通过排除相似选项找出正确答案。

**例题1**（2018山西）：
> 广义相对论涉及时空弯曲：A、B、C都涉及时空，D不涉及
> 选项D明显不同，当选

**例题2**（2017江西）：
> 演绎作品是在已有作品基础上：A、B、D都脱离不了原作品
> C是新作品，脱离原作品，当选

**例题3**（2017河南）：
> 超率累进税率关键在比率：B是数额非比率，C、D主体不统一
> A符合，当选

### 六、多定义判断

题干包含总定义和子定义（两个以上），解题要点：

#### 解题步骤

1. **看清提问**：明确问的是总定义还是子定义
2. **关注子定义**：理解子定义的关键特征
3. **不忽略总定义**：宏观奠定方向性，微观确定差异性
4. **比较选项**：三个相似+一个不同，另类选项常为正确答案

**例题1**（2012北京）：
> 对抗分为侵害、抗生、竞争
> 问"竞争"：两种生物+相互施加不利影响
> C只有一种生物，A、B是单方面损害，选D

**例题2**（2014联考）：
> 反事实思维分上行（想象比真实好）和下行（想象比真实坏）
> B与A、C、D不同，假设结果比原事实坏，属下行反事实思维

### 八、削弱型论证补充（概率类问题）

> 注：概率类问题是削弱型论证的一种特殊题型

#### 核心概念

概率类问题涉及两个或以上集合，**通过对比不同集合间具有某项特征的个体所占比例**来研究特征比率。

**关键**：看的是**比率**，不是绝对数量。

#### 解题方法

1. 明确题干中的概率计算方式
2. 对比不同集合的概率
3. 注意样本基数对概率的影响

**例题1**（2012国考）：
> 论题：父母吸烟导致儿童中耳炎
> 关键数据：78%患者来自二手烟家庭
> 削弱关键：D选项说明调查人群中80%来自二手烟家庭
> 计算：若800个二手烟家庭中78个患病，概率9.75% < 总概率78%，削弱论据

**例题2**（2010安徽）：
> 结论：大学生学术道德素质越来越差
> C选项：近10年本科毕业生数量大幅增加（绝对数量增加≠比率增加）

**例题3**（2015天津）：
> 论证：中等速度事故数量多→高速行驶更安全
> B选项：多数人中等速度开车，所以多数事故出在中等速度（数量多≠概率高）

### 九、定义判断解题技巧总结

| 方法 | 适用场景 | 核心思路 |
|------|----------|----------|
| **提取关键词** | 题干要素清晰 | 找主体、客体、主观、客观要素 |
| **归纳特征** | 题干成分多 | 用自己的话概括核心特征 |
| **隐含要点** | 从名称能推断 | 从被定义项本身找隐含信息 |
| **选项类聚** | 题干复杂 | 比较选项相似性，找不同 |
| **多定义抓子** | 有总定义和子定义 | 看准问题，重点分析子定义 |

### 十、常见陷阱

1. **主体不符**：选项主体与定义主体不一致
2. **夸大/缩小定义**：不自觉放大或缩小定义范围
3. **忽略提问方式**：看错"属于"或"不属于"
4. **主观判断**：不看题干而凭常识做题
5. **混淆时间/条件**：忽略定义中的时间、条件限定

### 一、图形推理速查

#### 数量类

| 考点 | 识别特征 | 规律类型 |
|------|----------|----------|
| **元素** | 图形由多个独立部分组成 | 元素种类、元素个数、部分数 |
| **面** | 封闭空间/区域 | 面数量、面积比例 |
| **角** | 乱绞丝、扇形、多边形加线 | 锐角、直角、总角数 |
| **线** | 直线/曲线明显 | 直线数、曲线数、总线条数 |
| **点** | 交点、切点 | 交点数（直直、曲曲、曲直） |
| **笔画** | 五角星、日字变形、多端点 | 一笔画/多笔画判断 |

#### 一笔画判定

| 条件 | 结论 |
|------|------|
| 奇点数 = 0 或 2 | 可一笔画 |
| 奇点数 > 2 | 笔画数 = 奇点数 ÷ 2 |
| 奇点成对出现 | 奇点一定是偶数个 |

#### 位置类

| 考点 | 识别特征 | 规律类型 |
|------|----------|----------|
| **平移** | 图形相同、位置变化 | 上下左右、循环移动 |
| **旋转** | 图形绕点转动 | 顺时针/逆时针、角度 |
| **翻转** | 图形镜像对称 | 左右翻转、上下翻转 |

#### 属性类

| 考点 | 识别特征 | 规律类型 |
|------|----------|----------|
| **对称性** | 图形对称 | 轴对称、中心对称、对称轴数量 |
| **曲直性** | 直线/曲线组成 | 全直、全曲、有曲有直 |
| **封闭性** | 封闭/开放图形 | 全封闭、全开放 |

#### 样式类

| 考点 | 识别特征 | 规律类型 |
|------|----------|----------|
| **叠加** | 图形叠加 | 去同存异、去异存同 |
| **遍历** | 九宫格/两组式 | 元素遍历所有位置 |

#### 重构类

| 考点 | 识别特征 | 解题方法 |
|------|----------|----------|
| **折纸盒** | 六面体展开图 | 相对面、相邻面、时针法 |
| **截面图** | 立体图形截面 | 截面形状分析 |

### 二、类比推理速查

#### 概念关系

| 关系类型 | 说明 | 示例 |
|----------|------|------|
| **全同关系** | A=B | 北京：中国首都 |
| **包含关系** | A包含B | 苹果：水果 |
| **交叉关系** | 有交集但不包含 | 医生：女性 |

| **条件关系** | 必要/充分条件 | 努力：成功 |

| 关系类型 | 说明 | 示例 |

### 三、逻辑判断速查

#### 基本逻辑原理

| 原理 | 公式 | 说明 |
|------|------|------|
| **逆否命题** | A→B ⇔ B→¬A | 原命题与逆否命题等价 |
| **矛盾关系** | A的矛盾是¬A | 必有一真一假 |
| **反对关系** | 不能同真，可以同假 | 上反对、下反对 |

#### 推理规则

| 规则 | 形式 | 示例 |
|------|------|------|
| **翻译推理** | 如果...那么... | 所有S都是P → 某个S是P |
| **德摩根定律** | ¬(A∧B) = ¬A∨¬B | 非(A且B) = 非A或非B |
| **德摩根定律** | ¬(A∨B) = ¬A∧¬B | 非(A或B) = 非A且非B |

#### 加强型论证

| 加强方式 | 力度 | 识别特征 |
|----------|------|----------|
| **补充前提** | ★★★★★ | "前提""假设""必要条件" |
| **对比实验** | ★★★★★ | 有实验组对照组 |
| **搭桥加强** | ★★★★☆ | 在论据论点间建立联系 |
| **加强论点** | ★★★☆☆ | 重复强调论点 |
| **加强论据** | ★★★☆☆ | 增加新论据、举例 |

#### 削弱型论证

| 削弱方式 | 力度 | 识别特征 |
|----------|------|----------|
| **否定前提** | ★★★★★ | 否定必要条件 |
| **因果倒置** | ★★★★★ | B才是A的原因 |
| **有因无果** | ★★★★☆ | 有A但没B（矛盾削弱） |
| **拆桥** | ★★★★☆ | 切断论据论点联系 |
| **对比实验** | ★★★★☆ | 否定前提一致性 |
| **另有他因** | ★★★☆☆ | C才是B的真正原因 |
| **削弱论点** | ★★★☆☆ | 直接否定论点 |
| **削弱论据** | ★★☆☆☆ | 否定论据或举反例 |
| **无因有果** | ★★☆☆☆ | 没A但有B |

#### 削弱力度对比（因果类）

```
因果倒置 > 有因无果（矛盾） > 另有他因 > 无因有果
```

#### 削弱力度对比（一般类）

```
否定前提 > 拆桥 > 削弱论点 > 削弱论据
```

### 六、常用排除技巧

| 技巧 | 说明 |
|------|------|
| **主体排除** | 选项主体与定义主体不一致 |
| **时间排除** | 选项时间与定义时间不符 |
| **绝对化排除** | 选项出现"所有""都""一定"等绝对词 |
| **比较排除** | 多个选项部分符合，选最符合的 |
| **否定提问排除** | 看清问"属于"还是"不属于" |
