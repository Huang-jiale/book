# 资料分析 · 模块导航

> 本模块基于《22 行测考点一本通》第二章 + 《资料分析理论课知识点笔记》整理，共 8 篇：
> 谋略 → 速算 → 基期现期 → 增长率增长量 → 比重平均数 → 倍数综合分析 → 理论课补遗。

## 一、学习路径（建议顺序）

```
资料分析 → 02 速算篇 截位直除·分数比较 → 03 基期与现期 → 04 增长率与增长量 → 05 比重与平均数 → 06 倍数与综合分析 → 07 理论课补遗 八大技巧·乘积·A非A
```

## 二、题型与核心公式速查

| 考点 | 识别标志 | 核心公式 |
|------|----------|----------|
| 基期量 | "求前面某时期" | 基期=(现期)/( 1+r) |
| 现期量 | "求后面某时期" | 现期=基期×(1+r) |
| 增长率 | "增长 + %" | r=(增长量)/( 基期) |
| 增长量 | "增长 + 单位" | 增长量=(现期)/( 1+r)× r=(现期)/( N+1) |
| 间隔增长率 | "中间隔一期" | r=r_1+r_2+r_1r_2 |
| 混合增长率 | 部分+整体 | 居中但不中，偏向基期量大者 |
| 比重 | "占" | 比重=(部分)/( 整体) |
| 平均数 | "均/每/单位" | 平均数=(总数)/( 个数) |
| 倍数 | "A 是 B 的 n 倍" | n=(A)/( B)；r=(A)/( B)-1 |

## 三、考场时间分配

- **总题量**：通常为 4 篇材料 × 5 题 = 20 题
- **建议用时**：≤ 25 分钟（平均每篇 6 分钟）
- **做题顺序**：图形 → 表格 → 文字 → 综合（见 01 谋略篇）
- **放弃原则**：综合分析第 5 题超过 2 分钟无进展，先蒙后跳

## 四、与其他模块关联

- 速算技巧（02 篇 + 07 补遗）是全部计算题的底层能力
- 比重/平均数（05 篇）与倍数（06 篇）常交叉命题
- A和非A 思想（07 补遗）是比重难题的快速解法

> **💡 提示**：一句话心法
> 资料分析不考计算，考"列对式子 + 看选项"。式子列好，截位直除，永远先看选项再动手。
