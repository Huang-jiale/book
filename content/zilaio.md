### 📖 知识点详解

#### 1.1 加法：高位叠加

**核心思路**：从最高位开始逐位相加，无需列竖式，直接口算出结果。

##### 🔹 示例1：两位数加减法（基础）

> **计算**：55 + 32 = ?
>
> 📊 **解题流程图**：
```
55 + 32
 │   │
 5+3=8  ← 十位相加
 │   │
 5+2=7  ← 个位相加
 ─────
  87
```
>
> ✅ **解析**：先算 5+3=8（十位），再算 5+2=7（个位），结果为87。

##### 🔹 示例2：三位数加法（进阶）

> **计算**：926 + 532 = ?
>
> 📊 **解题流程图**：
```
926 + 532
 │ │   │ │
 9+5=14  ← 百位
 │ │   │ │
 2+3=5   ← 十位
 │ │   │ │
 6+2=8   ← 个位
 ──────
 1458
```
>
> ✅ **解析**：先算 9+5=14，再算 2+3=5，最后算 6+2=8，结果为1458。

##### 🔹 示例3：多个多位数相加（挑战）

> **题目**：2389 + 2367 + 2351 + 2107 + 1892 =（　）
> A. 1.4万　B. 1.3万　C. 1.2万　D. 1.1万
>
> 📊 **解题流程图**：
```
选项分析：答案保留到千位 → 算数截位到百位

2389 → 24（百位）
2367 → 24
2351 → 24
2107 → 21
1892 → 19
─────────
24+24+24+21+19 = 112（千）= 1.12万

最接近1.1万 → 选D
```
>
> ✅ **解析**：答案保留到千位，所以算数截位到百位。即 24+24+24+21+19=112，答案为D。

#### 1.2 减法：划线减法

**核心思路**：通过插入临界值或划线对齐，将减法转化为口算。

##### 🔹 示例1：临界值法（基础）

> **计算**：314 - 289 = ?
>
> 📊 **解题流程图**：
```
314 和 289 都接近 300

314 - 289 = 314 - 300 + 11
                   │
               14 + 11 = 25
```
>
> ✅ **解析**：以300为临界值，314-300=14，再加上多减的11，得25。

##### 🔹 示例2：普通数值划线法（进阶）

> **计算**：926 - 532 = ?
>
> 📊 **解题流程图**：
```
9 2 6
│ │ │
│ │ └── 6-2=4
│ └──── 2-3 不够减 → 借位
└────── 92-53=39
─────────
  394
```
>
> ✅ **解析**：先算 9-5=4，由于2-3不够减，和前面一起算 92-53=39，最后 6-2=4，结果为394。

---

#### 1.3 乘法：化乘法为加法

**核心思路**：将乘法拆分为多个简单加法，避免复杂竖式计算。

##### 🔹 示例1：两位数×一位数（基础）

> **计算**：73 × 4 = ?
>
> 📊 **解题流程图**：
```
73 × 4 = 70×4 + 3×4
         │       │
       280  +  12
         ───────
         292
```
>
> ✅ **解析**：拆成 70×4=280 和 3×4=12，相加得292。

##### 🔹 示例2：两位数×两位数（进阶）

> **计算**：75 × 34 = ?
>
> 📊 **解题流程图**：
```
千位  百位  十位  个位
 2    1    2    0    ← 十位×十位 (7×3=21, 7×4=28)
 2    8         
      1    5         ← 个位×个位 (5×4=20, 3×5=15)
 ─────────────────
 2    5    5    0
```
>
> ✅ **解析**：先算十位×十位放千位百位，再算个位×个位放十位个位，最后十×个放百位十位，得2550。

##### 🔹 示例3：整数×百分数（挑战）

> **计算**：1624 × 26% = ?
>
> 📊 **解题流程图**：
```
26% = 25% + 1%

1624 × 26% = 1624 × 25% + 1624 × 1%
             │           │
          1624÷4      1624×1%
             │           │
           406      +  16.24
             ───────────
              422.24
```
>
> ✅ **解析**：将26%拆为25%+1%，1624÷4=406，1624×1%=16.24，相加得422.24。

#### 1.4 分数拆分思想

**核心思路**：通过化1法、化半法、凑整法，将复杂分数转化为简单计算。

##### 🔹 示例1：化1法（基础）

> **计算**：254/248 = ?
> A. 100.4%　B. 101.4%　C. 102.4%　D. 103.4%
>
> 📊 **解题流程图**：
```
254/248 = (248+6)/248
         = 248/248 + 6/248
         = 1 + 6/2.5
         = 1 + 2.4%
         = 102.4%
```
>
> ✅ **解析**：将分子拆为248+6，分别除以248，得1+2.4%=102.4%，选C。

##### 🔹 示例2：凑整法（进阶）

> **计算**：1144/2309 = ?
> A. 48.8%　B. 49.5%　C. 5.12%　D. 5.37%
>
> 📊 **解题流程图**：
```
1144/2309 = (1155-11)/2309
           = 1155/2309 - 11/23
           = 50% - 0.5%
           = 49.5%
```
>
> ✅ **解析**：将分子凑为1155-11，1155/2309≈50%，11/23≈0.5%，得49.5%，选B。

##### 🔹 技巧3：乘0.9 = 错位相减

#### 1.6 截位直除

**核心思路**：根据选项差距，保留有效数字进行除法计算。

##### 🔹 示例1：截位规则（基础）

> **规则说明**：
```
0.16554 截两位 → 0.17（第三位5，四舍五入）
0.16554 截三位 → 0.166
```

##### 🔹 示例2：一步除法（进阶）

> **题目**：12.85 / 43.89 = ?
> A. 21.7%　B. 26.6%　C. 29.3%　D. 37.7%
>
> 📊 **解题流程图**：
```
选项分析：
- 首位相同(2)，第二位不同
- 第二位最小差：9-6=3 > 首位2
→ 截两位

12.85 ÷ 43.89 ≈ 12.85 ÷ 44
               = 0.292...
               ≈ 29.3%
```
>
> ✅ **解析**：因为26.6%和29.3%的第二位差(9-6=3)大于首位(2)，所以截两位。12.85÷44≈29.3%，选C。

##### 🔹 示例3：多步除法（挑战）

> **题目**：584.5/2341 ÷ 414.2/1006 = ?
> A. 0.6　B. 0.8　C. 1.2　D. 1.7
>
> 📊 **解题流程图**：
```
多步除法 → 分子分母都截位

584.5/2341 ≈ 58/23
414.2/1006 ≈ 41/10

58/23 × 10/41 = 580/943 ≈ 0.6
```
>
> ✅ **解析**：分子分母都截位，58/23 × 10/41 ≈ 0.6，选A。

#### 1.7 量级处理

##### 🔹 示例1：尾数法（基础）

> **题目**：49283 - 30391 = ?
> A. 3501　B. 7906　C. 12545　D. 18892
>
> 📊 **解题流程图**：

选项尾数不同 → 用尾数法

```

##### 🔹 示例2：量级判断（进阶）

> **题目**：89591 / 14% = ?
> A. 200万　B. 640万　C. 20万　D. 64万
>
> 📊 **解题流程图**：
```
89591 / 14% = 89591 × 100 / 14
            ≈ 89600 ÷ 14
            = 6400
            = 640万
```
>
> ✅ **解析**：计算过程中只看有效数字，不考虑量级。896÷14=64，加上万级单位，选B。

#### 1.8 分数大小比较

##### 🔹 方法1：一大一小，分子大分数大

> **比较**：16.06/42.70 与 8.22/39.54
>
> 📊 **分析图**：
```
16.06 > 8.22（分子大）
42.70 > 39.54（分母大）

一大一小 → 分子大分数大
16.06/42.70 > 8.22/39.54
```

##### 🔹 方法2：同同小小，横看增长速度

> **比较**：16.06/42.70 与 8.22/39.54
>
> 📊 **分析图**：
```
分子：16 → 8，增长100%
分母：42 → 39，增长7.7%

分子增长快 → 分子大分数大
16.06/42.70 > 8.22/39.54
```

##### 🔹 方法3：化1法

> **比较**：1182/1185 与 8690/8704
>
> 📊 **分析图**：
```
1182/1185 = 1 - 3/1185
8690/8704 = 1 - 14/8704

比较 3/1185 和 14/8704：
- 3→14，近5倍
- 1185→8704，近7倍

分母增速大 → 14/8704 更小 → 1-14/8704 更大

所以 1182/1185 < 8690/8704
```

##### 🔹 方法4：化除为乘

> **比较**：179.1/270.7 与 60%
>
> 📊 **分析图**：
```
A/B > 60% → A > B×60%

179.1 与 270.7×60% = 162.42

179.1 > 162.42 → 179.1/270.7 > 60%
```

### 🧩 情景模拟

#### 📝 综合例题：复杂加减混合运算

> **题目**：某公司2021年四个季度销售额分别为：Q1=2389万，Q2=2367万，Q3=2351万，Q4=2107万，2020年全年=1892万。问2021年总销售额约为多少万？
>
> A. 9000　B. 9100　C. 9200　D. 9300
>
> 📊 **解题流程图**：
```
第一步：计算 2021 年总销售额（高位叠加）
2389 + 2367 + 2351 + 2107
  ↓ 截位到百位（看选项保留两位有效）
24 + 24 + 24 + 21 = 93（百万）≈ 9300 万
  ↓ 精确核算
2389 + 2367 = 4756
4756 + 2351 = 7107
7107 + 2107 = 9214 万

第二步：对照选项
9214 万介于 9200(C) 与 9300(D) 之间，
截位估算偏高约 86 万，精确值 9214 更接近 9200 → 选 C
```
>
> ✅ **完整解析**：使用高位叠加法先估算 2389+2367+2351+2107≈24+24+24+21=93（百万）≈9300 万；再精确相加 2389+2367=4756，4756+2351=7107，7107+2107=9214 万。本题求的是 2021 年总销售额（2020 年 1892 万为干扰项），9214 万最接近选项 **C（9200 万）**。

### ⚠️ 易错点提醒

- ❌ **截位错误**：多步除法时分子分母都要截位，一步除法只截分母
- ❌ **量级忽略**：计算时只看有效数字，最后加上量级单位
- ❌ **临界值选错**：减法时要选择两个数都接近的临界值
- ❌ **百化分记错**：12.5%=1/8，11.1%=1/9，不要混淆
- ❌ **化除为乘滥用**：当选项首位相同、第二位也相同时，慎用化除为乘

## 第二章 基期量

> 💡 **核心要点**：基期量计算是资料分析的基础，核心公式为「基期 = 现期 - 增长量 = 现期 ÷ (1+r)」，根据选项差距选择截位直除或化除为乘。

---

### 📌 知识结构图

```
基期量
├── 一、同比和环比
│   ├── 同比：与去年同期相比
│   └── 环比：与上一统计周期相比
├── 二、基期公式
│   ├── 基期 = 现期 - 增长量
│   ├── 基期 = 现期 ÷ (1+r)
│   ├── 基期 = 增长量 ÷ r
│   └── 化除为乘：|r|≤5%时，A/(1±r) ≈ A×(1∓r)
├── 三、基期比较
│   ├── 转化为分数比较
│   ├── 横看增长速度
│   └── 化1法/化除为乘
├── 四、基期和差
│   ├── 分别计算后相减
│   └── 先算现期和差，再调整增量差
└── 五、常识与百化分
    ├── 规模=人均×人数
    └── 贸易顺差=出口-进口
```

---

### 🎯 核心公式速查表

| 公式 | 表达式 | 适用条件 | 注意事项 |
|------|--------|---------|---------|
| 基期（已知现期+增长量） | 基期 = 现期 - 增长量 | 直接相减 | 注意单位统一 |
| 基期（已知现期+增长率） | 基期 = 现期 ÷ (1+r) | 最常用 | 看选项截位 |
| 基期（已知增长量+增长率） | 基期 = 增长量 ÷ r | 追及问题 | r不能为0 |
| 化除为乘 | A/(1+r) ≈ A×(1-r) | \|r\|≤5% | 选项首位相同慎用 |
| 基期和差 | A/(1+a) - B/(1+b) | 分别计算 | 先算现期差再调整 |

---

### 📖 知识点详解

#### 2.1 同比和环比

**核心思路**：明确时间比较基准，同比跨年度，环比跨相邻周期。

> 📊 **对比图**：
```
同比（跨年度）
────────────────────────────────────────
2019年Q1    2020年Q1    2021年Q1
   ↕            ↕
"今年Q1"    "去年Q1"

环比（相邻周期）
────────────────────────────────────────
2021年5月 → 2021年6月 → 2021年7月
                ↕
        "上月"    "本月"
```

#### 2.2 基期计算

##### 🔹 示例1：公式法（基础）

> **题目**：2021年，全国城市供水总量673.34亿立方米，同比增长6.96%，则2020年全国城市供水总量约为？
> A. 600　B. 620　C. 630　D. 724
>
> 📊 **解题流程图**：
```
分析选项：
- 选项差距小（600 vs 630）
- 保留三位有效数字

计算过程：
673.34 ÷ 1.07 ≈ 630

验证：630 × 1.07 = 674.1 ≈ 673.34 ✓
```
>
> ✅ **解析**：选项差距小，保留三位，673.34÷1.07≈630，选C。

##### 🔹 示例2：增长量÷增长率法（进阶）

> **题目**：2016年，棉花单产每公顷增加63.3公斤，提高约6%。则2015年棉花单产为多少？
> A. 1118　B. 1092　C. 1055　D. 1003
>
> 📊 **解题流程图**：
```
基期 = 增长量 ÷ 增长率
     = 63.3 ÷ 6%
     = 63.3 ÷ 0.06
     ≈ 1055
```
>
> ✅ **解析**：直接用增长量除以增长率，63.3÷6%=1055，选C。

##### 🔹 示例3：化除为乘（挑战）

> **题目**：2021年6月我国原油日均产量为55.6万吨，增长了2.8%，则2020年6月我国原油日均产量是？
> A. 52.8　B. 53.2　C. 54.1　D. 55.5
>
> 📊 **解题流程图**：
```
|r|=2.8% ≤ 5%，可用化除为乘

基期 = 现期 ÷ (1+r) ≈ 现期 × (1-r)
     = 55.6 × (1-2.8%)
     = 55.6 - 55.6×2.8%
     ≈ 55.6 - 0.56×3
     = 55.6 - 1.68
     = 53.92
     ≈ 54.1（百化分精算）
```
>
> ✅ **解析**：|2.8%|≤5%，可用化除为乘。55.6-0.56×3≈54，选C。

#### 2.3 基期比较

**核心思路**：将基期比较转化为分数比较，用增长速度法或化1法判断。

##### 🔹 示例1：增长速度法（进阶）

> **题目**：2020年四个城市拥堵指数和增速如下，问2019年最拥堵的城市是？
>
> | 城市 | 2020年拥堵指数 | 增速% |
> |------|---------------|--------|
> | 北京 | 2.063 | 1.15 |
> | 上海 | 1.932 | 11.08 |
> | 重庆 | 2.260 | 4.40 |
> | 南京 | 1.822 | 6.84 |
>
> A. 北京　B. 上海　C. 重庆　D. 南京
>
> 📊 **解题流程图**：
```
基期 = 现期 ÷ (1+r)，转化为分数比较：
北京：2.06/1.01
上海：1.9/1.11（增速大，基期小）→ 排除
重庆：2.26/1.04
南京：1.8/1.068（基数小）→ 排除

比较北京和重庆：
- 分子：2.06 → 2.26，增长约10%
- 分母：1.01 → 1.04，增长约3%
- 分子增速快 → 重庆基期大

答案：重庆
```
>
> ✅ **解析**：先排除增速大（上海）和基数小（南京）的选项，再比较北京和重庆，分子增长快则分数大，选C。

#### 2.4 基期和差

**核心思路**：先算现期和差，再根据增量大小调整基期和差。

##### 🔹 示例1：基期和差判断（挑战）

> **题目**：2021年中国向"一带一路"沿线国家出口1137.9亿美元，增长24.5%；进口131.6亿美元，增长24.5%。则2020年贸易顺差约为？
> A. 1129　B. 1253　C. 808　D. 1006
>
> 📊 **解题流程图**：
```
第一步：计算现期差
出口 - 进口 = 1137.9 - 131.6 = 1006.3

第二步：分析增量
出口增量 > 进口增量（因为出口基数大）
基期和差 = 现期和差 - 增量差
        < 现期和差

第三步：判断选项
基期和差 < 1006
只有C（808）< 1006
```
>
> ✅ **解析**：现期差为1006，出口增量大于进口增量，基期和差<1006，选C。

##### 🔹 示例2：基期和差精算（进阶）

> **题目**：2019年第一季度邮政寄递服务110.4亿元，增长7.4%；3月份37.1亿元，下降1.6%。则2018年1-2月收入约为？
> A. 44　B. 65　C. 82　D. 103
>
> 📊 **解题流程图**：
```
法一：分析法
Q1 - 3月 = 110.4 - 37.1 = 73.3

Q1增量 > 3月增量（正增长 > 负增长）
基期和差 < 73.3
排除C、D

增速小，差值不会太大 → 选B(65)

法二：精算
Q1基期 = 110 ÷ 1.07 ≈ 103
3月基期 = 37.1 ÷ 0.984 ≈ 37.7
1-2月基期 = 103 - 37.7 = 65.3 ≈ 65
```
>
> ✅ **解析**：基期和差小于现期和差73，增速小差值不大，选B。

### 🧩 情景模拟

#### 📝 综合例题：复杂基期比较

> **题目**：2020年五省GDP如下，问2019年GDP最低的省份是？
>
> | 省份 | 2020年GDP(万亿) | 增速% |
> |------|------------------|--------|
> | 甲省 | 5.2 | 8.5 |
> | 乙省 | 4.8 | 12.3 |
> | 丙省 | 3.6 | 5.2 |
> | 丁省 | 4.1 | 9.8 |
>
> 📊 **解题流程图**：
```
基期 = 现期 ÷ (1+r)

甲省：5.2/1.085 ≈ 4.79
乙省：4.8/1.123 ≈ 4.27  ← 增速高，基数小
丙省：3.6/1.052 ≈ 3.42  ← 最小
丁省：4.1/1.098 ≈ 3.73

乙省和丁省增速高，但基数不一定最低
甲省增速低，但基数中等
丙省基数最小（3.6），增速也低 → 基期最低

验证：丙省基期 = 3.6/1.052 ≈ 3.42
      丁省基期 = 4.1/1.098 ≈ 3.73
      
最低为丙省
```
>
> ✅ **完整解析**：增速高的省份（乙、丁）基期会被拉低，但基数本身低（丙省）才是关键。丙省基数最小且增速较低，基期最低。

### ⚡ 速算技巧总结

| 技巧 | 适用场景 | 操作要点 |
|------|---------|---------|
| 截位直除 | 一般基期计算 | 看选项差距，保留2-3位 |
| 化除为乘 | \|r\|≤5% | A/(1+r)≈A×(1-r) |
| 增长率比较法 | 基期大小比较 | 分子增速快则分数大 |
| 化1法 | 分子分母接近 | 比较1-差值 |
| 基期和差速判 | 两个基期相减 | 先算现期差，再调增量差 |

### ⚠️ 易错点提醒

- ❌ **混淆同比环比**：同比是去年同期，环比是上月/上季度
- ❌ **化除为乘滥用**：选项首位相同、第二位也相同时慎用
- ❌ **忽略r的符号**：增长率为负时，分母是(1-r)不是(1+r)
- ❌ **基期和差方向**：增量a>增量b，基期和差<现期和差

## 第三章 现期量

> 💡 **核心要点**：现期量计算核心是「追赶」——保持增长量或增长率不变，推算未来达到某一水平的年份。

---

### 📌 知识结构图

```
现期量
├── 一、现期追赶
│   ├── 保持增长量不变
│   │   ├── 计算年增长量
│   │   └── 推算超过目标值的年份
│   ├── 保持增长率不变（一年）
│   │   └── 基期 × r = 增量
│   ├── 保持增长率不变（多年）
│   │   └── 用间隔增长率
│   └── 不给增长率，给增长量
│       └── 用增长量代替，答案大于计算值
└── 二、技巧总结
    ├── 增长量不变：精确计算增量
    └── 增长率不变：先估算再精算
```

---

### 🎯 核心公式速查表

| 类型 | 公式 | 适用条件 | 注意事项 |
|------|------|---------|---------|
| 增长量不变 | 现期 = 基期 + n×年增长量 | 保持增量 | 精确计算增长量 |
| 增长率不变（一年） | 现期 = 基期 × (1+r) | 给出增长率 | 估算后调整 |
| 增长率不变（多年） | 用间隔增长率 | 多年追赶 | 先估总增速 |
| 不给增长率 | 用增长量代替 | 答案>计算值 | 基期大则增长量大 |

---

### 📖 知识点详解

#### 3.1 保持增长量不变

**核心思路**：根据往年增长量推算未来，注意精确计算避免临界值。

##### 🔹 示例1：增长量不变（基础）

> **题目**：2015年社会消费品零售额300931亿元，2016年332316亿元，若从2016年开始年增量保持不变，首次超过40万亿元的年份是？
> A. 2017　B. 2018　C. 2019　D. 2020
>
> 📊 **解题流程图**：
```
第一步：计算年增长量（精确计算）
332316 - 300931 = 31385

第二步：计算差距
400000 - 332316 = 67684

第三步：计算所需年数
67684 ÷ 31385 ≈ 2.16年

2年增量：2 × 31385 = 62770 < 67684
3年增量：3 × 31385 = 94155 > 67684
→ 需要3年

2016 + 3 = 2019
```
>
> ✅ **解析**：年增量为31400，还差67700，两年62800不够，需3年，选C。

---

#### 3.2 保持增长率不变（一年）

##### 🔹 示例1：一年增长率（基础）

> **题目**：2018年电子政务市场规模3106.9亿元，增长8.6%，按此增速2019年规模约为？
> A. 3270　B. 3370　C. 3470　D. 3570
>
> 📊 **解题流程图**：
```
法一：估算
8.6% ≈ 10%
3106.9 + 310 = 3416.9
实际值 < 3416.9 → 选B(3370)

法二：精算
3106.9 × 8.6% = 31 × 8.6 = 266.6
3106.9 + 266.6 = 3373.5 ≈ 3370
```
>
> ✅ **解析**：把8.6%看作10%，3106.9+310=3416.9，结果小于此值，选B。

---

#### 3.3 保持增长率不变（多年）

##### 🔹 示例1：多年增长率（挑战）

> **题目**：2018年疫苗市场292.6亿元，2019年311.2亿元，增长6.36%，按此增速哪年突破400亿元？
> A. 2021　B. 2022　C. 2023　D. 2024
>
> 📊 **解题流程图**：
```
第一步：估算总增速
311.2 → 400，增长率约29%

第二步：估算4年增长率
6.36% × 4 ≈ 25.44%

第三步：精算（间隔思维）
r ≈ 6.36% + 6.36% + 6.36%×6.36%
  ≈ 12.72% + 0.4% = 13.12%

4年 ≈ 13.12% × 2 + 13.12%²
    ≈ 26.24% + 1.7% = 27.94%

27.94% < 29%，4年不够
→ 需要5年，到2024
```
>
> ✅ **解析**：4年增长率不足29%，需5年突破400亿，选D。

#### 3.4 不给增长率，给增长量

##### 🔹 示例1：增长量代替法（进阶）

> **题目**：2019年7月上旬聚乙烯价格8081.7元/吨，比上期上涨152.6元/吨，按此环比涨幅，7月中旬价格约为？
> A. 7929.1　B. 8031.5　C. 8134.3　D. 8236.9
>
> 📊 **解题流程图**：
```
基期（8081.7）> 上期基期
基期大 → 增长量 > 152.6

如果用152.6代替：
8081.7 + 152.6 = 8234.3

实际值 > 8234.3
只有D(8236.9) > 8234.3
```
>
> ✅ **解析**：基期大则增长量比152.6大，计算值8234.3，实际值更大，选D。

##### 🔹 示例2：比例类比法（挑战）

> **题目**：2020年种子出口2.28万吨，2021年2.47万吨，按此增速2022年出口量约为？
> A. 2.58　B. 2.68　C. 2.78　D. 2.88
>
> 📊 **解题流程图**：
```
第一步：计算增长量
2.47 - 2.28 = 0.19

第二步：用增长量代替
2.47 + 0.19 = 2.66
多个选项>2.66 → 需要精算

第三步：比例类比
0.19到2.28是10倍关系
0.19的十分之一 = 0.02
2.66 + 0.02 = 2.68
```
>
> ✅ **解析**：增长量0.19，基期2.28，增量与基期10:1关系，增量增大约0.02，选B。

### 🧩 情景模拟

#### 📝 综合例题：追赶问题

> **题目**：2020年A公司营收100亿元，B公司80亿元。A公司年增长5%，B公司年增长10%。问B公司追上A公司的年份？
>
> 📊 **解题流程图**：
```
设n年后B追上A：
100 × (1.05)ⁿ = 80 × (1.10)ⁿ

(1.10/1.05)ⁿ = 100/80 = 1.25
(1.0476)ⁿ = 1.25

n=5: 1.0476⁵ ≈ 1.26 > 1.25
n=4: 1.0476⁴ ≈ 1.20 < 1.25

需要5年

验证：
A: 100×1.05⁵ = 100×1.28 = 128
B: 80×1.10⁵ = 80×1.61 = 128.8

2025年B追上A
```
>
> ✅ **完整解析**：设n年后相等，列方程求解。n≈5年，2025年B追上A。

## 第四章 增长量

> 💡 **核心要点**：增长量 = 现期 - 基期 = 基期 × r = 现期/(1+r) × r，根据|r|大小选择不同计算方法。

---

### 📌 知识结构图

```
增长量
├── 一、增长量计算
│   ├── 公式法：现期 - 基期
│   ├── 百化分法：现期/(1+r) × r
│   ├── |r|<5%：增长量 ≈ 现期 × r
│   ├── |r|>50%：分析法/代入法
│   └── 拉动增长率：部分增量/整体基期
├── 二、增长量比较
│   ├── 给出现期和基期：直接算前两位
│   ├── 给出现期和增长率：现期大增长率大则增量大
│   └── 增长率倍数比较法
├── 三、年均增长量
│   └── 总增长量 ÷ n年
└── 四、名义增长率
    └── R名义 = R实际 + R通胀 + R实际×R通胀
```

---

### 🎯 核心公式速查表

| 类型 | 公式 | 适用条件 | 技巧 |
|------|------|---------|------|
| 增长量 | 现期 - 基期 | 直接相减 | 高位叠加/划线减法 |
| 增长量（百化分） | 现期/(1+r) × r | r可百化分 | 转为分数计算 |
| \|r\|\<5% | 增长量 ≈ 现期 × r | 小增长率 | 直接乘法 |
| \|r\|>50% | 分析法/代入法 | 大增长率 | 排除法 |
| 拉动增长率 | 部分增量/整体基期 | 拉动增长 | 注意分母是基期 |
| 年均增长量 | 总增长量 ÷ n | n年规划 | 注意n的取值 |

---

### 📖 知识点详解

#### 4.1 增长量计算

##### 🔹 示例1：直接相减法（基础）

> **题目**：2020年广东省财政科技支出955.73亿元，2021年982.76亿元，增长了多少？
> A. 7.03　B. 17.03　C. 27.03　D. 37.03
>
> 📊 **解题流程图**：
```
增长量 = 现期 - 基期
      = 982.76 - 955.73
      = 27.03
```
>
> ✅ **解析**：直接相减得27.03，选C。

##### 🔹 示例2：百化分法（进阶）

> **题目**：2022年1-7月城乡居民生活用电7586亿千瓦，增长12.5%，比上一年多多少？
> A. 672　B. 843　C. 925　D. 1020
>
> 📊 **解题流程图**：
```
12.5% = 1/8

增长量 = 现期 / (1+1/8) × 1/8
      = 7586 / 9
      ≈ 843
```
>
> ✅ **解析**：12.5%=1/8，7586÷9=843，选B。

##### 🔹 示例3：|r|<5%近似（基础）

> **题目**：2017年棉花产量549万吨，增产3.5%，比2016年约增产多少万吨？
> A. 7　B. 19　C. 31　D. 48
>
> 📊 **解题流程图**：
```
|r|=3.5% < 5%
增长量 ≈ 现期 × r
       = 549 × 3.5%
       ≈ 5.5 × 3.5
       = 19.25
```
>
> ✅ **解析**：|3.5%|<5%，直接用549×3.5%≈19，选B。

##### 🔹 示例4：大增长率分析法（挑战）

> **题目**：2019年6月全国发行地方债8996亿元，增长68.37%，比上一年多多少？
> A. 6151　B. 5953　C. 3653　D. 3043
>
> 📊 **解题流程图**：
```
r=68.37% ≈ 2/3

法一：百化分
增长量 = 8996 ÷ (2+3) × 2
      = 1800 × 2
      = 3600
      ≈ 3653（接近）

法二：代入验证
增长100%才4500，排除AB
代入C：基期 = 3653 × 1.68 ≈ 6100 ≠ 5343
实际基期 = 8996 ÷ 1.68 ≈ 5355
8996 - 5355 = 3641 ≈ 3653 ✓
```
>
> ✅ **解析**：68.37%≈2/3，8996÷5×2=3600，接近3653，选C。

##### 🔹 示例5：拉动增长率（进阶）

> **题目**：2017年电信业务收入12620亿元，增长6.4%。移动数据收入5489亿元，增长26.7%，拉动电信业务增长约多少个百分点？
> A. 7.2　B. 8.2　C. 9.7　D. 10.7
>
> 📊 **解题流程图**：
```
部分增量 = 5489 × 26.7%
        = 5489 ÷ 4 ≈ 1370
        （实际比1370大，约1470）

整体基期 = 12620 ÷ 1.064 ≈ 11860

拉动增长率 = 1470 ÷ 11860
           ≈ 12.4%（接近但需精确）

更精确计算：
部分增量 = 5489 - 5489/1.267 ≈ 5489 - 4332 = 1157
整体基期 = 12620/1.064 = 11861

```

### 📌 知识结构图

增长率

#### 5.1 增长率计算

##### 🔹 示例1：百分点计算（基础）

> **题目**：2020年汽车销量2531.1万辆，下降1.9%，降幅比上半年收窄15.0个百分点，问上半年降幅？
> A. 10个百分点内　B. 10-12个百分点　C. 12-14个百分点　D. 15个百分点以上
>
> 📊 **解题流程图**：
```
降幅收窄 = 下半年降幅小 → 上半年降幅大

上半年降幅 = 全年降幅 + 收窄百分点
          = 1.9% + 15.0%
          = 16.9%
          → 15个百分点以上
```
>
> ✅ **解析**：收窄即"低"，所以要加，1.9%+15%=16.9%，选D。

#### 5.2 增长率比较

> A. 2011　B. 2013　C. 2014　D. 2017
>

```
增长率 = 增量/基期，转化为分数比较

增量数据：2011:150, 2013:130, 2014:170, 2017:251

排除B(增量最小)

比较A和C：
- A：150/基期A
- C：170/基期C

- 基期增长：基期A→基期C，增长>13%（因为中间有2年）
- 基期增速大 → 分母大分数小 → A > C

比较A和D：
- 增量：150→251，增长67%
- 基期：基期A→基期D（中间6年），增长>67%
- 基期增速大 → A > D

答案为A
```
>
> ✅ **解析**：用增量/基期比较，分子增速快则分数大。A的增量小但基期更小，增速最快，选A。

## 第六章 间隔增长率

> 💡 **核心要点**：间隔增长率 r = r₁ + r₂ + r₁×r₂，当r₁、r₂均<10%时可忽略r₁r₂项，间隔倍数=间隔增长率+1。

---

### 📌 知识结构图

```
间隔增长率
├── 一、公式
│   ├── r = r₁ + r₂ + r₁×r₂
│   ├── |r₁|,|r₂|<10%：忽略r₁r₂
│   ├── 间隔倍数 = r + 1
│   ├── 间隔基期 = 现期/(1+r)
│   └── 间隔增长量 = 现期/(1+r) × r
├── 二、多年间隔
│   ├── 各年增长率相加估算
│   └── 实际值 > 相加值
├── 三、逆向运用
│   └── 已知r₁和r间，求r₂
└── 四、特定增长率比较
    └── 错位相加法判断
```

---

### 🎯 核心公式速查表

| 类型 | 公式 | 技巧 |
|------|------|------|
| 间隔增长率 | r = r₁ + r₂ + r₁×r₂ | 小时忽略乘积 |
| 间隔倍数 | 倍数 = r + 1 | 先求增长率再加1 |
| 间隔基期 | 基期 = 现期/(1+r) | 百化分 |
| 逆向运用 | r₂ = (r间 - r₁)/(1+r₁) | 解方程 |

---

### 📖 知识点详解

#### 6.1 间隔增长率公式

##### 🔹 示例1：基础计算（基础）

> **题目**：2014年1-2月西藏出口额增长7.2倍，2014年比2012年同期多少倍？
> A. 0.2　B. 0.6　C. 1.7　D. 8.2
>
> 📊 **解题流程图**：
```
2014年增长率 = 720%
2013年增长率 = -79.7%

r间 = r₁ + r₂ + r₁×r₂
    = 720% + (-79.7%) + 7.2×(-79.7%)
    = 640.3% - 573.84%
    = 66.46%

间隔倍数 = 1 + 66.46% = 1.66 ≈ 1.7
```
>
> ✅ **解析**：代入公式，r₁r₂=7.2×(-80%)=-576%，得66%增长，1.66倍，选C。

##### 🔹 示例2：忽略乘积项（进阶）

> **题目**：2019年增长24%，较2019年增长16%，求2020年比2019年？
>
> 📊 **解题流程图**：
```
已知：r₁=24%（2021比2020），r间=16%（2021比2019）
求：r₂（2020比2019）

r间 = r₁ + r₂ + r₁×r₂
16% = 24% + r₂ + 24%×r₂
-8% = 1.24×r₂
r₂ = -6.45%
→ 下降了不到10%
```
>
> ✅ **解析**：用逆向公式，r₂=(16%-24%)/(1+24%)=-6.45%，选D。

##### 🔹 示例3：多年间隔估算（挑战）

> **题目**：2015年服务业投资额31.19万亿，2012-2015年均增长15.9%，则2015年比2012年增长约？
> A. 16%　B. 56%　C. 48%　D. 32%
>
> 📊 **解题流程图**：
```
估算：16%×3 = 48%
实际值 > 48%（因为有r₁r₂相乘）

精算：
第1年：16%
第2年：16%+16%+16%×16% = 34.56%
第3年：34.56%+16%+34.56%×16%
     = 50.56% + 5.53%
     = 56.09% ≈ 56%
```
>
> ✅ **解析**：年均16%，3年累计>48%，精算约56%，选B。

| 技巧 | 适用场景 |
|------|---------|
| 忽略乘积 | r₁,r₂均<10%时，r₁r₂<1% |
| 加法估算 | 多年间隔，先加后微调 |
| 逆向公式 | 已知r₁和r间，求r₂ |

## 第七章 乘积增长率

### 🎯 核心公式速查表

|------|------|---------|
| 总额=单价×数量 | R_额 = R_单 + R_数 + R_单×R_数 | 出现单价和数量 |
| 部分=整体×比重 | R_部 = R_整 + R_重 + R_整×R_重 | 出现占比/比重 |

### 📖 知识点详解

#### 7.1 总额=单价×数量

##### 🔹 示例1：基础计算（基础）

> **题目**：2017年长江流域播种面积下降14.9%，单产下降3.6%，求总产量下降率？
> A. 4%　B. 7%　C. 15%　D. 18%
>
> 📊 **解题流程图**：
```
总产量 = 面积 × 单产

R = R_面积 + R_单产 + R_面积×R_单产
  = -14.9% + (-3.6%) + (-14.9%)×(-3.6%)
  = -18.5% + 0.54%
  = -17.96%
  ≈ -18%
```
>
> ✅ **解析**：化积增长率公式，-14.9%-3.6%+0.54%≈-18%，选D。

#### 7.2 部分=整体×比重

##### 🔹 示例1：比重变化处理（进阶）

> **题目**：2019年海洋生产总值89415亿元，增长6.2%。三次产业比重从59.1%变为60.0%，求第三产业增加值增长率？

>
> 📊 **解题流程图**：
```
第三产业 = 总产值 × 比重

第一步：计算比重增长率

第二步：代入乘积公式
R_第三 = R_总 + R_重 + R_总×R_重
       = 6.2% + 1.5% + 6.2%×1.5%
       = 7.7% + 0.093%
       = 7.79% ≈ 7.8%
```
>
> ✅ **解析**：先算比重增长1.5%，再代入公式得7.8%，选C。

## 第八章 年均增长率

> 💡 **核心要点**：年均增长率比较用现期/基期（n相同时），计算用(1+r)ⁿ=现期/基期，r<10%时可用估算公式。

---

### 📌 知识结构图

```
年均增长率
├── 一、年均增长率比较
│   ├── n相同：直接比较现期/基期
│   ├── 现期<基期：增长率为负
│   └── 给出现期和增长量：比较增长量/现期
├── 二、年均增长率计算
│   ├── 原公式：(1+r)ⁿ = 现期/基期（r>10%）
│   ├── 估算公式：r ≤ (现期/基期-1)÷n（r<10%）
│   ├── 记住平方数
│   └── 间隔思维
└── 三、常见平方数
    └── 11²=121, 12²=144, ..., 19²=361
```

---

### 🎯 核心公式速查表

| 类型 | 公式 | 适用条件 |
|------|------|---------|
| 比较（n相同） | 现期/基期越大，r越大 | 基期年数相同 |
| 比较（给增长量） | 增长量/现期越大，r越大 | 只有现期和增长量 |
| 计算（r>10%） | (1+r)ⁿ = 现期/基期 | 大增长率 |
| 计算（r<10%） | r ≤ (现期/基期-1)÷n | 小增长率 |

### 📖 知识点详解

#### 8.1 年均增长率比较

##### 🔹 示例1：n相同比较（基础）

> **题目**：①甘肃、②广东、③上海、④浙江2016-2021年集成电路产量年均增速从高到低排序？
> A. ④①②③　B. ④①③②　C. ①④②③　D. ①④③②
>
> 📊 **解题流程图**：
```
n都是5年（2016-2021），直接比较现期/基期

先找最小值：
- 广东约2倍+
- 上海约1倍多
→ 上海最小，排除BD

比较①甘肃和④浙江：
- 倍数都是3倍左右
- 需要精算

甘肃：643÷197 ≈ 3.26
浙江：230÷74 ≈ 3.11

甘肃 > 浙江 → ①>④

顺序：①>④>②>③
```
>
> ✅ **解析**：n相同，直接比较现期/基期。先排除最小值，再精算接近值，选C。

#### 8.2 年均增长率计算

##### 🔹 示例1：平方数法（进阶）

> **题目**：2016年湿地面积61.68万亩，2018年104.24万亩，年均增长率约？
> A. 25%　B. 30%　C. 35%　D. 40%
>
> 📊 **解题流程图**：
```
法1：平方数
(1+r)² = 104/61 ≈ 1.67

1.3² = 1.69 ≈ 1.67
→ r ≈ 30%

法2：估算
r ≤ (104/61-1)÷2 = 0.345÷2 = 17.25%
（这是低估，因为公式是≤）
实际接近30%

法3：验证
30%+30%+30%×30% = 69%
104/61-1 = 67% ≈ 69%
→ r ≈ 30%
```
>
> ✅ **解析**：(1+r)²=1.67，1.3²=1.69，r≈30%，选B。

## 第九章 混合增长率

> 💡 **核心要点**：部分混合得到整体，混合增长率居中（介于两部分之间），偏向基期量大的部分。

---

### 📌 知识结构图

```
混合增长率
├── 一、主体混合
│   ├── 识别：部分+整体关系（"其中"）
│   ├── 方法：部分写两边，整体写中间
│   └── 居中思维：偏向基期大的
├── 二、时间混合
│   ├── 识别：累计+当月
│   └── 方法：累计增速介于当月增速之间
├── 三、核心方法：线段法
│   ├── 量之比 = 距离之比的反比
│   └── 用线段长度表示差距
└── 四、增长率差距大时
    └── 用基期计算，不用现期
```

---

### 🎯 核心公式速查表

| 类型 | 方法 | 技巧 |
|------|------|------|
| 主体混合 | 部分+部分=整体 | 居中偏向 |
| 时间混合 | 累计=前期+当月 | 大大则大 |
| 线段法 | 量之比 = 距离反比 | 量小距离大 |
| 精算 | 用基期量 | 差距大时 |

### 📖 知识点详解

#### 9.1 主体混合

##### 🔹 示例1：基础混合（基础）

> **题目**：2018年末常住人口1302.66万人，其中户籍454.70万人增长4.6%，非户籍847.97万人增长3.6%，求常住人口增长率？
> A. 3.6%　B. 3.9%　C. 4.7%　D. 4.2%
>
> 📊 **解题流程图**：
```
线段法：

非户籍 847.97(3.6%)----┬----户籍 454.70(4.6%)
                     │
                常住人口 r%

分析：
- 混合增长率在3.6%~4.6%之间
- 非户籍量大，偏向3.6%

量之比 ≈ 850:450 ≈ 2:1
距离之比 = 1:2

r = 3.6% + (4.6%-3.6%) × 1/3
  = 3.6% + 0.33%
  ≈ 3.9%
```
>
> ✅ **解析**：非户籍量大，偏向3.6%，量比约2:1，距离反比，3.6%+0.33%≈3.9%，选B。

##### 🔹 示例2：时间混合（进阶）

> **题目**：2018年3月国产品牌手机出货量2699.5万部，下降29%；1-3月7586.4万部，下降27.8%。求1-2月下降率？
> A. 25.5%　B. 26.6%　C. 27.1%　D. 28.4%
>
> 📊 **解题流程图**：
```
时间混合：1-2月 + 3月 = 1-3月

线段法：

3月 2700(-29%)----┬----1-2月 4886(?)
                  │
             1-3月 7586(-27.8%)

分析：
- 混合增长率在-29%到r之间
- 居中思维：-27.8%靠近r（因为1-2月量大）

量之比 ≈ 2700:4900 ≈ 3:5
距离之比 = 5:3

-27.8% = (-29% + r)/2 不对

正确计算：
r = -27.8% + (-27.8%-(-29%)) × 3/8
  = -27.8% + 1.2% × 3/8
  = -27.8% + 0.45%
  = -27.35% ≈ -27.1%
```
>
> ✅ **解析**：1-2月量大，混合增速靠近1-2月。精算得-27.1%，选C。

#### 9.2 大大则大（时间混合速判）

##### 🔹 示例1：累计与当月比较

> **题目**：2020年3-12月，当月发电量同比增速快于累计增速的月份有几个？
> A. 5　B. 6　C. 7　D. 8
>
> 📊 **解题流程图**：
```
时间混合：累计 = 前期累计 + 当月

大大则大原理：
累计增速上升 → 当月增速 > 累计增速
累计增速下降 → 当月增速 < 累计增速

分析：
- 1-2月累计：2.5%
- 1-3月累计：0.2%（下降）
- 3月当月：需要>1-3月才能让累计上升

看哪些月份累计增速比上月大：
4月>3月，5月>4月，6月>5月，7月>6月，9月>8月，10月>9月，11月>10月
共7个月
```
>
> ✅ **解析**：累计增速上升意味着当月>累计。满足条件的有7个月，选C。

#### 📝 综合例题：混合增长率精算

> **题目**：2016年参加城镇职工基本医保女性1.4亿人，比2011年增长21.5%；参加城镇居民基本医保女性1.9亿人，增长1.5倍。求整体增长？
> A. 0.7倍　B. 1.2倍　C. 1.7倍　D. 2.2倍
>
> 📊 **解题流程图**：
```
增长率差距大（21.5% vs 150%），不能用现期，要转基期

第一步：计算基期
职工2011年：1.4÷1.215 ≈ 1.15
居民2011年：1.9÷2.5 = 0.76

第二步：混合计算
整体2011年 = 1.15 + 0.76 = 1.91
整体2016年 = 1.4 + 1.9 = 3.3

增长率 = (3.3-1.91)/1.91 = 1.39/1.91 ≈ 0.73

用线段法：
职工1.15(21.5%)----┬----居民0.76(150%)
                   │
              整体1.91(r%)

居中为85%，偏向21.5%
→ 整体增长率在21.5%~85%之间

量之比 ≈ 1.15:0.76 ≈ 1.5:1
距离之比 = 1:1.5 = 2:3

r = 21.5% + (150%-21.5%) × 2/5
  = 21.5% + 51.4%
  = 72.9% ≈ 0.73倍
```
>
> ✅ **完整解析**：增长率差距大时转基期计算，用线段法精算得72.9%增长，约0.73倍，最接近0.7倍，选A。

### 📖 知识点详解

#### 10.1 现期比重

##### 🔹 示例1：基础比重计算（基础）

> **题目**：2019年A市已被成功实施发明专利5.2万件，占有效发明专利数的58.4%，求有效发明专利数？
> A. 9　B. 10　C. 11　D. 12
>
> 📊 **解题流程图**：
```
有效发明专利 = 已实施 ÷ 比重
            = 5.2 ÷ 58.4%
            ≈ 5.2 ÷ 0.58
            ≈ 9
```
>
> ✅ **解析**：5.2÷58.4%≈5.2÷0.58≈9，选A。

##### 🔹 示例2：比重连乘（进阶）

> **题目**：数字产业化占GDP比重最大的年份是？
> | 年份 | 数字化占数字经济 | 数字经济占GDP |
> |------|----------------|-------------|
> | 2015 | 27.5% | 25.7% |
> | 2017 | 32.9% | 22.6% |
> | 2019 | 36.2% | 19.8% |
> | 2020 | 38.6% | 19.1% |
>
> 📊 **解题流程图**：
```
数字产业化占GDP = 数字化占数字经济 × 数字经济占GDP

2015：27.5% × 25.7% ≈ 7.07%
2017：32.9% × 22.6% ≈ 7.44%
2019：36.2% × 19.8% ≈ 7.17%
2020：38.6% × 19.1% ≈ 7.37%

最大为2017年
```
>
> ✅ **解析**：比重连乘，2017年最大，选B。

##### 🔹 示例3：比重连除（进阶）

> **题目**：2021年制造业增加值4.17万亿元，占GDP35.8%，第二产业占GDP44.5%，求制造业占第二产业比重？
> A. 72.8%　B. 78.7%　C. 80.4%　D. 83.3%
>
> 📊 **解题流程图**：
```
制造业占第二产业 = 制造业占GDP ÷ 第二产业占GDP
               = 35.8% ÷ 44.5%
               ≈ 0.358/0.445
               ≈ 0.804 = 80.4%
```
>
> ✅ **解析**：35.8%÷44.5%≈80.4%，选C。

##### 🔹 示例4：增长贡献率（进阶）

> **题目**：2023年全省GDP128222.2亿元，增长5.8%，第三产业66236.7亿元，增长5.1%，求第三产业对经济增长贡献率？
> A. 40.2%　B. 45.7%　C. 51.2%　D. 56.8%
>
> 📊 **解题流程图**：
```
增长贡献率 = 第三产业增量 ÷ 整体增量
≈ (66×5.1%) ÷ (128×5.8%)
= 5.1 ÷ (2×5.8)
= 5.1 ÷ 11.6
≈ 44%

接近45.7%
```
>
> ✅ **解析**：≈66×5.1/(128×5.8)=5.1/11.6≈44%，接近45.7%，选B。

#### 10.2 现期平均数

##### 🔹 示例1：基础平均数（基础）

> **题目**：2021年H省电子商务平台87个，交易金额5354.93亿元，Z市有44个平台，交易4239.04亿元，求除Z市外其他地区平均每个平台交易金额？

除Z市外：
- 平台数 = 87 - 44 = 43

##### 🔹 示例2：月均比较（进阶）

符合条件的省份有6个

#### 10.3 现期倍数

##### 🔹 示例1：倍数与增长率区分（基础）

```
"多多少倍" = 倍数 - 1 = A/B - 1

上半年进口 = 30193 - 4124 = 26069

## 第十一章 基期比重、平均数、倍数

> 💡 **核心要点**：基期比重 = A/B × (1+b)/(1+a)，通过比较a和b判断与现期比重大小关系。

---

### 📌 知识结构图

```
基期比重、平均数、倍数
├── 一、基期比重
│   ├── 公式：A/B × (1+b)/(1+a)
│   ├── 估算：先算A/B，再看a和b
│   ├── 精算：A/B ± 0.1A/B
│   └── 现期-基期比重精算
├── 二、基期平均数
│   └── 公式：A/B × (1+b)/(1+a)
└── 三、基期倍数
│   ├── 公式：A/B × (1+b)/(1+a)
│   ├── 精算：直接代公式
│   └── 估算法：a>b时结果偏小
└── 四、A与非A思想
    └── 直接用比重求倍数
```

---

### 🎯 核心公式速查表

| 类型 | 公式 | 技巧 |
|------|------|------|
| 基期比重 | A/B × (1+b)/(1+a) | a<b时结果>A/B |
| 基期平均数 | A/B × (1+b)/(1+a) | 同上 |
| 基期倍数 | A/B × (1+b)/(1+a) | 同上 |
| 精算 | A/B - A/B×(a-b) | a<b时结果偏大 |

---

### 📖 知识点详解

#### 11.1 基期比重

##### 🔹 示例1：估算方法（基础）

> **题目**：2018年1-9月乘用车销量1726.0万辆，增长0.6%，中国品牌724.2万辆，下降1.5%，求2017年1-9月中国品牌占比？
> A. 41.9%　B. 42.9%　C. 44.1%　D. 46.2%
>
> 📊 **解题流程图**：
```
第一步：算现期比重 A/B = 724.2/1726.0 ≈ 41.9%

第二步：比较a和b
a = -1.5%（中国品牌增速）
b = 0.6%（整体增速）
a < b → 基期比重 > 现期比重

所以基期比重大于41.9%
接近42.9% → 选B
```
>
> ✅ **解析**：a<b，基期>现期，41.9%偏小，接近42.9%，选B。

##### 🔹 示例2：精算法（进阶）

> **题目**：同上，精确计算
>
> 📊 **解题流程图**：
```
精算：A/B - A/B×(a-b)
= 41.9% - 41.9%×(-1.5%-0.6%)
= 41.9% + 41.9%×2.1%
= 41.9% + 0.88%
= 42.78% ≈ 42.9%
```
>
> ✅ **解析**：用现期比重减去两期比重差，得42.78%，接近42.9%，选B。

---

#### 11.2 基期倍数

##### 🔹 示例1：基期倍数计算（进阶）

> **题目**：2017年海水养殖产量93.1万吨，增长3%，海洋捕捞产量53万吨，下降3.4%，求2016年养殖是捕捞的多少倍？
> A. 0.6　B. 0.8　C. 1.6　D. 1.8
>
> 📊 **解题流程图**：
```
现期倍数 = 93.1/53 ≈ 1.76

基期倍数 = A/B × (1+b)/(1+a)
       = 1.76 × (1-3.4%)/(1+3%)
       = 1.76 × 0.966/1.03
       = 1.76 × 0.938
       ≈ 1.65

a=3%, b=-3.4%, a>b → 基期倍数 < 现期倍数
接近1.6 → 选C
```
>
> ✅ **解析**：a>b，基期倍数偏小，现期1.76，基期约1.6，选C。

---

#### 11.3 A与非A思想

##### 🔹 示例1：倍数转换（挑战）

> **题目**：2014年末博物馆3658个，占文物机构43.5%，博物馆接待观众71774万人次，占85.2%，求平均每家博物馆接待观众是其他文物机构的多少倍？
> A. 2　B. 4.5　C. 7.5　D. 11
>
> 📊 **解题流程图**：
```
A（博物馆）的比重：43.5%（机构），85.2%（观众）
非A（其他机构）的比重：56.5%（机构），14.8%（观众）

A平均/A整体 = 85.2%/43.5%
非A平均/非A整体 = 14.8%/56.5%

A平均 ÷ 非A平均 = (85.2%/43.5%) ÷ (14.8%/56.5>)
             = (85.2/43.5) × (56.5/14.8)
             ≈ 1.96 × 3.82
             ≈ 7.5
```
>
> ✅ **解析**：用比重直接求，(85.2%/43.5%)÷(14.8%/56.5%)≈7.5，选C。

---

### 🧩 情景模拟

#### 📝 综合例题：基期比重精算

> **题目**：2020年末艺术表演团体17581个，减少214个，从业人员43.69万人，增加2.44万人。其中部门所属团体2060个占11.7%，从业人员10.75万人占24.6%，求2019年末平均每个部门所属团体从业人数是全国所有团体的多少倍？
> A. 0.5　B. 0.8　C. 1.3　D. 2.1
>
> 📊 **解题流程图**：
```
法1（精算）：
基期部门所属：
- 机构：2060/(1-214/17581) ≈ 2060/0.988 ≈ 2085
- 人员：10.75/(1+2.44/43.69) ≈ 10.75/1.056 ≈ 10.18

基期全国：
- 机构：17581+214 = 17795
- 人员：43.69-2.44 = 41.25

部门平均 = 10.18/2085 ≈ 0.00488
全国平均 = 41.25/17795 ≈ 0.00232
倍数 = 0.00488/0.00232 ≈ 2.1

法2（比重法）：
24.6%/11.7% ÷ (1-24.6%)/(1-11.7%)
= 2.1 × 0.854/0.754
≈ 2.1 × 1.13
≈ 2.1（因为基期变化小）
```
>
> ✅ **完整解析**：用比重直接计算，24.6%/11.7%≈2.1，基期变化不大，选D。

### ⚡ 速算技巧总结

| 技巧 | 适用场景 |
|------|---------|
| 估算法 | 快速判断基期与现期大小关系 |
| 精算法 | 选项接近时用 A/B±0.1A/B |
| A与非A | 用比重直接求倍数 |

---

### ⚠️ 易错点提醒

- ❌ **方向判断**：a<b时基期>现期，a>b时基期<现期
- ❌ **精算公式**：A/B - A/B×(a-b)，注意符号
- ❌ **A与非A**：分母是1-比重，不要忘记

## 第十二章 两期比重、平均数

> 💡 **核心要点**：两期比重比较看a和b大小，a>b则上升；平均数增长率=(a-b)/(1+b)。

---

### 📌 知识结构图

```
两期比重、平均数
├── 一、两期比重
│   ├── 公式：A/B × (a-b)/(1+a)
│   ├── 升降判断：a>b上升，a<b下降
│   ├── 升降幅度：<|a-b|
│   └── 给出现期和基期：直接相减
├── 二、两期平均数
│   ├── 公式：A/B × (a-b)/(1+a)
│   ├── 比较：直接看a和b
│   └── 增长量：A/B × (a-b)/(1+a)
├── 三、平均数增长率
│   └── 公式：(a-b)/(1+b)
├── 四、逆运用
│   └── 已知升降判断a和b大小
└── 五、乘积vs平均数增长率
    ├── 乘法关系：乘积增长率
    └── 除法关系：平均数增长率
```

---

### 🎯 核心公式速查表

| 类型 | 公式 | 技巧 |
|------|------|------|
| 两期比重升降 | 比较a和b | a>b上升 |
| 两期比重变化 | A/B×(a-b)/(1+a) | <\|a-b\| |
| 平均数增长量 | A/B×(a-b)/(1+a) | 同上 |
| 平均数增长率 | (a-b)/(1+b) | 分母是1+b |
| 乘积增长率 | R₁+R₂+R₁R₂ | 乘法关系 |
| 平均数增长率 | (a-b)/(1+b) | 除法关系 |

---

### 📖 知识点详解

#### 12.1 两期比重

##### 🔹 示例1：升降判断（基础）

> **题目**：2021年前三季度文化企业营收84205亿元，增长21.8%，其中新闻信息服务9847亿元增长22.1%，内容创作17693亿元增长18.6%，求比重增加的行业个数？
> A. 3　B. 4　C. 5　D. 6
>
> 📊 **解题流程图**：
```
b = 21.8%（整体增速）

各行业增速：
- 新闻信息：22.1% > 21.8% → 上升 ✓
- 内容创作：18.6% < 21.8% → 下降
- 创意设计：24.0% > 21.8% → 上升 ✓
- 文化传播：30.1% > 21.8% → 上升 ✓
- 文化投资：13.8% < 21.8% → 下降
- 文化娱乐：35.3% > 21.8% → 上升 ✓
- 文化辅助：18.3% < 21.8% → 下降
- 文化装备：17.8% < 21.8% → 下降
- 文化消费：22.0% > 21.8% → 上升 ✓

上升的行业：5个
```
>
> ✅ **解析**：直接比较a和b，a>b则上升，有5个行业上升，选C。

##### 🔹 示例2：升降幅度（进阶）

> **题目**：2020年软件业务收入81658亿元，增长13.3%，利润10676亿元，增长7.8%，求营业利润率变化？
> A. 上升2个百分点以上　B. 下降2个百分点以上　C. 上升不到2个百分点　D. 下降不到2个百分点
>
> 📊 **解题流程图**：
```
a = 7.8%（利润增速）
b = 13.3%（收入增速）
a < b → 比重下降

|a-b| = 5.5%
变化幅度 < 5.5%

精确计算：
现期比重 = 10676/81658 ≈ 13%
变化 = 13% × (7.8%-13.3%)/(1+7.8%)
     = 13% × (-5.5%)/1.078
     ≈ -0.66%
     ≈ -0.7个百分点

下降不到2个百分点
```
>
> ✅ **解析**：a<b，下降。变化<|a-b|=5.5%，精算约0.7个百分点，选D。

##### 🔹 示例3：给出现期和基期（进阶）

> **题目**：2018年文化企业营收89257亿元，文化服务业34454亿元；2020年98514亿元，文化服务业45964亿元，求2020年文化服务业占比比2018年？
> A. 下降不到5个百分点　B. 下降5个百分点以上　C. 上升不到5个百分点　D. 上升5个百分点以上
>
> 📊 **解题流程图**：
```
2020年比重 = 45964/98514 ≈ 46%
2018年比重 = 34454/89257 ≈ 38%

变化 = 46% - 38% = +8%
→ 上升超过5个百分点
```
>
> ✅ **解析**：直接相减，46%-38%=8%，上升超过5个百分点，选D。

---

#### 12.2 两期平均数

##### 🔹 示例1：平均数增长量（进阶）

> **题目**：2019年商品房销售面积171558万平，下降0.1%，销售额159725亿元，增长6.5%，求销售均价变化？
> A. 增长580元　B. 增长710元　C. 下降580元　D. 下降710元
>
> 📊 **解题流程图**：
```
均价 = 销售额/面积
a = 6.5%（销售额增速）
b = -0.1%（面积增速）
a > b → 均价上升

增长量 = A/B × (a-b)/(1+a)
      = 159725/171558 × (6.5%-(-0.1%))/(1+6.5%)
      ≈ 0.93 × 6.6/106.5
      ≈ 0.93 × 0.062
      ≈ 0.0576万元
      ≈ 576元
      ≈ 580元
```
>
> ✅ **解析**：a>b，均价上升。增长量≈580元，选A。

##### 🔹 示例2：平均数增长率（进阶）

> **题目**：2016年餐饮收入35799亿元，增长10.8%，经营单位365.5万个，下降8.2%，求平均每个经营单位从业人数变化？
> A. 减少2%　B. 减少15%　C. 增加2%　D. 增加15%
>
> 📊 **解题流程图**：
```
平均 = 从业人数/经营单位
a = 5.7%（从业人数增速）
b = -8.2%（经营单位增速）

平均数增长率 = (a-b)/(1+b)
            = (5.7%-(-8.2%))/(1-8.2%)
            = 13.9%/0.918
            ≈ 15%

a>b → 增加
```
>
> ✅ **解析**：增长率=(5.7%+8.2%)/(1-8.2%)=13.9%/0.918≈15%，选D。

---

#### 12.3 逆运用

##### 🔹 示例1：已知升降判断a和b（挑战）

> **题目**：2019年上半年全国快递业务量277.5亿件，增长25.7%，业务收入3396.7亿元，增长23.7%。6月业务量54.6亿件，增长29.1%，收入643.2亿元，增长26.5%。问增速最快和最慢的地区？
> A. 东部、中部　B. 东部、西部　C. 中部、东部　D. 中部、西部
>
> 📊 **解题流程图**：
```
表格给出2018和2019年各地区占比

分析：
- 东部：比重上升 → a(东部) > b(全国)
- 中部：比重不变 → a = b
- 西部：比重下降 → a < b

所以东部增速最快，西部最慢
```
>
> ✅ **解析**：比重上升说明a>b，下降说明a<b。东部上升最快，西部下降最慢，选B。

### 🧩 情景模拟

#### 📝 综合例题：平均数增长率与间隔复合

> **题目**：2017年S市服务业小微样本企业总体营收105.39亿元，增长3.1%，比2016年回落15.7个百分点，资产938.58亿元，增长4.2%，比2016年下降0.9个百分点，求2017年平均每万元资产实现营业收入比2015年？
> A. 增长不到5%　B. 增长5%以上　C. 下降不到5%　D. 下降5%以上
>
> 📊 **解题流程图**：
```
求：2017年平均每万元资产实现营收比2015年变化
平均数 = 营收/资产

第一步：求2017年相对2016年的增长率
a（营收）：3.1%
b（资产）：4.2%

第二步：求2016年相对2015年的增长率
营收2016年增速 = 3.1%+15.7% = 18.8%
资产2016年增速 = 4.2%+0.9% = 5.1%

第三步：求2017年相对2015年的间隔增长率
营收：3.1%+18.8%+3.1%×18.8% ≈ 22.4%
资产：4.2%+5.1%+4.2%×5.1% ≈ 9.5%

第四步：平均数增长率
= (a-b)/(1+b)
= (22.4%-9.5%)/(1+9.5%)
= 12.9%/1.095
≈ 11.8%

a>b → 增长
11.8% > 5%
```
>
> ✅ **完整解析**：先求间隔增长率，再用平均数增长率公式，得11.8%增长，超过5%，选B。

- ❌ **升降幅度**：一定小于|a-b|
- ❌ **给出现期和基期**：直接相减，不要用公式

## 第十三章 A和非A思想

> 💡 **核心要点**：当题目涉及"超过特定比例"或"某部分是非A的多少倍"时，用A与非A思想转化为倍数关系。

---

### 📌 知识结构图

```
A和非A思想
├── 一、判断是否超过特定比例
│   ├── A/整体 > 50% → A > 非A
│   ├── A/整体 > 25% → A > 非A/3
│   └── A/整体 > 75% → A > 3×非A
├── 二、求A的平均是非A的多少倍
│   └── 公式：(A占比/非A占比) ÷ (A量/非A量)
├── 三、增长率与平均数
│   └── a>b则平均数上升
└── 四、综合应用
    └── 结合比重和增长率
```

---

### 🎯 核心公式速查表

| 类型 | 公式/方法 | 识别标志 |
|------|----------|---------|
| 超过50% | A > 非A | A/整体 > 1/2 |
| 超过25% | A > 非A/3 | A/整体 > 1/4 |
| 超过75% | A > 3×非A | A/整体 > 3/4 |
| 平均数倍数 | (A占比/非A占比)÷(A量/非A量) | 求平均数倍数 |
| 增长率判断 | a>b则平均数上升 | 两期平均数比较 |

---

### 📖 知识点详解

#### 13.1 判断是否超过特定比例

##### 🔹 示例1：超过50%（基础）

> **题目**：2014年博物馆接待观众71774万人次，占文物机构接待总人次的85.2%，判断：博物馆接待观众超过文物机构接待总人次的50%？
>
> 📊 **解题流程图**：
```
A/整体 > 50% → A > 非A

博物馆占比85.2% > 50%
→ 博物馆 > 其他文物机构

结论：√（正确）
```
>
> ✅ **解析**：85.2%>50%，即博物馆>其他文物机构，正确。

##### 🔹 示例2：超过特定比例（进阶）

> **题目**：判断：2014年博物馆数量占文物机构总数的43.5%，判断博物馆数量超过文物机构总数的25%？
>
> 📊 **解题流程图**：
```
A/整体 > 25% → A > 非A/3

博物馆占比43.5% > 25%
→ 博物馆 > 其他/3

结论：√（正确）
```
>
> ✅ **解析**：43.5%>25%，即博物馆>其他/3，正确。

---

#### 13.2 求A的平均是非A的多少倍

##### 🔹 示例1：基础计算（进阶）

> **题目**：2014年末博物馆3658个，占文物机构43.5%，博物馆接待观众71774万人次，占85.2%，求平均每家博物馆接待观众是其他文物机构的多少倍？
> A. 2　B. 4.5　C. 7.5　D. 11
>
> 📊 **解题流程图**：
```
A（博物馆）：
- 数量占比：43.5%
- 观众占比：85.2%

非A（其他机构）：
- 数量占比：1-43.5% = 56.5%
- 观众占比：1-85.2% = 14.8%

A平均/A整体 = 85.2%/43.5%
非A平均/非A整体 = 14.8%/56.5%

A平均 ÷ 非A平均 = (85.2%/43.5%) ÷ (14.8%/56.5%)
             = (85.2/43.5) × (56.5/14.8)
             ≈ 1.96 × 3.82
             ≈ 7.5
```
>
> ✅ **解析**：用比重直接求，(85.2%/43.5%)÷(14.8%/56.5%)≈7.5，选C。

#### 13.3 增长率与平均数

##### 🔹 示例1：增长率判断平均数（进阶）

> **题目**：2014-2017年出境旅游平均人次花费最多的年份是？
> A. 2014　B. 2015　C. 2016　D. 2017
>
> 📊 **解题流程图**：
```
给出每年出境旅游花费和人数的增长率

平均 = 花费/人数

判断：
- a(花费) > b(人数) → 平均上升
- a < b → 平均下降

分析：
- 2014→2015：a>b → 平均上升
- 2015→2016：a>b → 平均上升
- 2016→2017：a<b → 平均下降

所以2016年平均数最大
```
>
> ✅ **解析**：a>b则平均上升，a<b则平均下降。2015比2014升，2016比2015升，2017比2016降，最大为2016年，选C。

### 📖 知识点详解

#### 什么是百化分

**百化分**是将百分数转化为分数，从而将复杂的乘法运算转化为简单的除法运算。

**核心原理**：
- 1/n × 数值 = 数值 ÷ n
- 例如：25% × 800 = 1/4 × 800 = 800 ÷ 4 = 200

#### 为什么需要百化分

在资料分析中，经常遇到"A × r%"的形式，如果r%可以化为1/n，则：
- A × r% = A × 1/n = A ÷ n

这比直接计算 A × r% 快得多。

### 🧩 使用场景速查

#### 场景1：整数×百分数

```
1624 × 26% = 1624 × (25% + 1%)
             = 1624÷4 + 1624×1%
             = 406 + 16.24
             = 422.24
```

#### 场景2：增长量计算

```
|r| = 12.5% = 1/8
增长量 = 现期 ÷ (1+1/8) × 1/8 = 现期 ÷ 9

例：7586 × 12.5% = 7586 ÷ 9 = 843
```

#### 场景3：基期计算

```
|r| = 25% = 1/4
基期 = 现期 ÷ (1+1/4) = 现期 ÷ 5/4 = 现期 × 4/5

例：1000增长25%后是1250，基期=1000÷1.25=800
```

#### 场景4：化除为乘

```
|r| = 5% = 1/20
A/(1+5%) ≈ A×(1-5%) = A - A×5%

例：1000÷1.05≈1000-50=950
```

### 📝 练习题

1. 计算：5678 × 12.5% = ？
2. 计算：8900 × 11.1% = ？
3. 计算：7600增长14.3%后是多少？
4. 计算：4500增长16.7%后是多少？
5. 判断：一个数增长6.25%后是2560，原数是多少？

**答案**：
1. 5678 ÷ 8 = 709.75
2. 8900 ÷ 9 = 989
3. 7600 × (1+1/7) = 7600 × 8/7 = 8686
4. 4500 × (1+1/6) = 4500 × 7/6 = 5250
5. 2560 ÷ (1+1/16) = 2560 × 16/17 = 2410
