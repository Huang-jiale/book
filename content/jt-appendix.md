## 一、图形推理速查

### 数量类

| 考点 | 识别特征 | 规律类型 |
|------|----------|----------|
| **元素** | 图形由多个独立部分组成 | 元素种类、元素个数、部分数 |
| **面** | 封闭空间/区域 | 面数量、面积比例 |
| **角** | 乱绞丝、扇形、多边形加线 | 锐角、直角、总角数 |
| **线** | 直线/曲线明显 | 直线数、曲线数、总线条数 |
| **点** | 交点、切点 | 交点数（直直、曲曲、曲直） |
| **笔画** | 五角星、日字变形、多端点 | 一笔画/多笔画判断 |

### 一笔画判定

| 条件 | 结论 |
|------|------|
| 奇点数 = 0 或 2 | 可一笔画 |
| 奇点数 > 2 | 笔画数 = 奇点数 ÷ 2 |
| 奇点成对出现 | 奇点一定是偶数个 |

### 位置类

| 考点 | 识别特征 | 规律类型 |
|------|----------|----------|
| **平移** | 图形相同、位置变化 | 上下左右、循环移动 |
| **旋转** | 图形绕点转动 | 顺时针/逆时针、角度 |
| **翻转** | 图形镜像对称 | 左右翻转、上下翻转 |

### 属性类

| 考点 | 识别特征 | 规律类型 |
|------|----------|----------|
| **对称性** | 图形对称 | 轴对称、中心对称、对称轴数量 |
| **曲直性** | 直线/曲线组成 | 全直、全曲、有曲有直 |
| **封闭性** | 封闭/开放图形 | 全封闭、全开放 |

### 样式类

| 考点 | 识别特征 | 规律类型 |
|------|----------|----------|
| **叠加** | 图形叠加 | 去同存异、去异存同 |
| **遍历** | 九宫格/两组式 | 元素遍历所有位置 |

### 重构类

| 考点 | 识别特征 | 解题方法 |
|------|----------|----------|
| **折纸盒** | 六面体展开图 | 相对面、相邻面、时针法 |
| **截面图** | 立体图形截面 | 截面形状分析 |

## 二、类比推理速查

### 概念关系

| 关系类型 | 说明 | 示例 |
|----------|------|------|
| **全同关系** | A=B | 北京：中国首都 |
| **包含关系** | A包含B | 苹果：水果 |
| **交叉关系** | 有交集但不包含 | 医生：女性 |
| **全异关系** | A∩B=∅ | 猫：狗 |
| **并列关系** | 同级并列 | 苹果：香蕉 |

### 映射关系

| 关系类型 | 说明 | 示例 |
|----------|------|------|
| **功能关系** | A的功能是B | 汽车：运输 |
| **材料关系** | A由B制成 | 桌子：木材 |
| **因果关系** | A导致B | 下雨：洪水 |
| **顺序关系** | 时间/逻辑顺序 | 播种：收获 |
| **条件关系** | 必要/充分条件 | 努力：成功 |

### 语义关系

| 关系类型 | 说明 | 示例 |
|----------|------|------|
| **近义关系** | 词义相近 | 高兴：快乐 |
| **反义关系** | 词义相反 | 高：低 |
| **比喻关系** | 本体与喻心 | 月亮：玉盘 |
| **象征关系** | 象征意义 | 红色：喜庆 |

## 三、逻辑判断速查

### 基本逻辑原理

| 原理 | 公式 | 说明 |
|------|------|------|
| **逆否命题** | A→B ⇔ B→¬A | 原命题与逆否命题等价 |
| **矛盾关系** | A的矛盾是¬A | 必有一真一假 |
| **反对关系** | 不能同真，可以同假 | 上反对、下反对 |

### 推理规则

| 规则 | 形式 | 示例 |
|------|------|------|
| **翻译推理** | 如果...那么... | 所有S都是P → 某个S是P |
| **德摩根定律** | ¬(A∧B) = ¬A∨¬B | 非(A且B) = 非A或非B |
| **德摩根定律** | ¬(A∨B) = ¬A∧¬B | 非(A或B) = 非A且非B |

### 加强型论证

| 加强方式 | 力度 | 识别特征 |
|----------|------|----------|
| **补充前提** | ★★★★★ | "前提""假设""必要条件" |
| **对比实验** | ★★★★★ | 有实验组对照组 |
| **搭桥加强** | ★★★★☆ | 在论据论点间建立联系 |
| **加强论点** | ★★★☆☆ | 重复强调论点 |
| **加强论据** | ★★★☆☆ | 增加新论据、举例 |

### 削弱型论证

| 削弱方式 | 力度 | 识别特征 |
|----------|------|----------|
| **否定前提** | ★★★★★ | 否定必要条件 |
| **因果倒置** | ★★★★★ | B才是A的原因 |
| **有因无果** | ★★★★☆ | 有A但没B（矛盾削弱） |
| **拆桥** | ★★★★☆ | 切断论据论点联系 |
| **对比实验** | ★★★★☆ | 否定前提一致性 |
| **另有他因** | ★★★☆☆ | C才是B的真正原因 |
| **削弱论点** | ★★★☆☆ | 直接否定论点 |
| **削弱论据** | ★★☆☆☆ | 否定论据或举反例 |
| **无因有果** | ★★☆☆☆ | 没A但有B |

### 削弱力度对比（因果类）

```
因果倒置 > 有因无果（矛盾） > 另有他因 > 无因有果
```

### 削弱力度对比（一般类）

```
否定前提 > 拆桥 > 削弱论点 > 削弱论据
```

## 四、定义判断速查

### 解题方法

| 方法 | 适用场景 | 核心思路 |
|------|----------|----------|
| **提取关键词** | 题干要素清晰 | 主体、客体、主观、客观 |
| **归纳特征** | 题干成分多 | 概括核心特征 |
| **隐含要点** | 名称能推断 | 从被定义项找隐含信息 |
| **选项类聚** | 题干复杂 | 比较选项相似性 |
| **多定义抓子** | 有总定义子定义 | 看准问题，重点分析子定义 |

### 常见陷阱

- 主体不符
- 夸大/缩小定义
- 看错提问方式（属于/不属于）
- 凭常识而非题干判断

## 六、常用排除技巧

| 技巧 | 说明 |
|------|------|
| **主体排除** | 选项主体与定义主体不一致 |
| **时间排除** | 选项时间与定义时间不符 |
| **绝对化排除** | 选项出现"所有""都""一定"等绝对词 |
| **比较排除** | 多个选项部分符合，选最符合的 |
| **否定提问排除** | 看清问"属于"还是"不属于" |
