## 一、逻辑判断概述

### 1. 大纲分析

每道题给出一段陈述，这段陈述被假设是正确的，不容置疑的。要求报考者根据这段陈述，运用一定的逻辑推论，选择一个最恰当的答案。

### 2. 核心要点

| 要点 | 说明 |
|------|------|
| **前提不容置疑** | 前提属于非黑即白，关注细节思维不发散 |
| **必然性推理答案唯一** | 不要带入常识，纯靠逻辑去做 |
| **论证类题目用朴素思维** | 先用生活中朴素的逻辑思维做排除 |
| **答案不唯一时选最优** | 考虑优先原则，选相对好的答案 |

### 3. 常见考点分类

| 分类 | 内容 |
|------|------|
| **基本逻辑原理** | 单句翻译、复句翻译、易错关联词、矛盾关系、反对关系、推出关系、等价关系、模态命题 |
| **推理类题型** | 翻译推理、真假推理、分析推理、归纳推理、解释推理、数学推理、类推比较 |
| **论证类题型** | 一般类论点加强型、一般类论点削弱型、因果类论点加强型、因果类论点削弱型 |

## 二、五个复句翻译

复句翻译是将长复杂的文字语言转化为箭头语言的过程。

### （1）充分条件

**定义**：如果A能推出B，那么A就是B的充分条件。

**翻译**：A→B

**记忆口诀**：有他就行放前面

#### 常见关联词

| 关联词 | 翻译 |
|--------|------|
| 如果A，那么B | A→B |
| 若A，那么B | A→B |
| 所有A都是B | A→B |
| 只要A，就B | A→B |
| 凡是A，都B | A→B |

---

### （2）必要条件

**常见关联词**

| 关联词 | 翻译 |
|--------|------|
| 只有B，才A | A→B |
| B是A的必要条件 | A→B |
| B是A的前提 | A→B |
| A的基础是B | A→B |
| 为了A，一定B | A→B |
| A离不开B | A→B |

**记忆口诀**：没他不行放后面

**万能方法**：判断出谁是必不可少的条件，把必要条件放后面。

**示例**："人类为了能生存，一定要有氧气" → 氧气必不可少 → 氧气放后面 → 生存→氧气

---

### （3）逆否命题

**形式**：A→B 等价于 -B→-A

**四大要点**：
1. 充分条件：有他就行放前面
2. 必要条件：没他不行放后面
3. 肯前必肯后
4. 否后必否前

**注意**：否前肯后得不出任何确定性结论

**例题1（2018上海）**

> 领导干部如果没有底线思维，就不能做到严格自律。而只有不忘初心，才能始终保持底线思维。也只有始终坚守理想信念，才能不忘初心。

**解析**：翻译得到：自律→底线思维→不忘初心→理想信念。B选项正确。

**例题3（2018浙江）**

> 如果不学习电吉他，阿健就当不了乐队主唱；如果他想玩乐器，他会选择学习电吉他；如果他不玩乐器，他就当主唱。

**解析**：主唱→电吉他。玩乐器→电吉他。不玩乐器→主唱→电吉他。发现不管他是否玩乐器，都会选择学习电吉他。

---

### （4）联言命题

**形式**：A且B

**性质**：一假即假，同真才真

#### 常见关联词

| 关联词 | 翻译 |
|--------|------|
| 既A又B | A且B |
| 不但A而且B | A且B |
| 不仅A还B | A且B |
| 虽然A但是B | A且B |
| A，B | A且B |
| 同时A，B | A且B |

**例题（2018广州）**

> 只有具有良好的逻辑思维能力并且具有物理学专业背景的人，才能胜任这个岗位。

**解析**：翻译得到：胜任→逻辑且物理。B选项"从未学习过物理学知识的小李胜任了这个岗位"不可能为真。

---

### （5）选言命题

**形式**：A或B

**性质**：一真即真，两假才假

**推论**：如果"A或B"正确，且A错误，则B必然正确。

**例题（2018广东）**

> 某围棋队有选手会在比赛时喝茶，他们或者喝红茶，或者喝绿茶。

**解析**：喝茶→红茶或绿茶。Ⅱ正确，队员喝茶时一定是红茶或绿茶，不可能是黑茶。

## 三、八个单句翻译

| 序号 | 命题 | 等价翻译 |
|------|------|----------|
| 1 | 所有的A都是B | A→B |
| 2 | 没有A不是B | A→B |
| 3 | 所有的A都不是B | A→-B 也等价于 B→-A |
| 4 | 没有A是B | A→-B |
| 5 | 不是A的都是B | -A→B |
| 6 | 不是A的都不是B | -A→-B |
| 7 | A和B至少选一个 | A或B |
| 8 | A和B至多选一 | -A或-B |

**特别注意**：
- "不都"等价于"并非所有"，也就是"有的不"的意思
- "都不"是"所有不"的意思
- 两者意思截然不同，切忌混为一谈

---

## 四、七个易错关联词

### （1）除非A，否则B

**翻译**：-A→B

**方法**：后面的非A不要动，B没有否定词就直接"非A→B"

### （2）除非A，否则不B

**翻译**：-A→-B

### （3）当且仅当A时，B

**翻译**：A→B 且 B→A（充分必要条件）

### （4）因为A，所以B

**注意**：因果关系和推出关系是完全不同的逻辑关系！

| 情况 | 翻译 |
|------|------|
| A的发生必然引起B的反应 | A→B |
| A是引起B不可或缺的原因 | B→A |

### （5）要么A，要么B

**性质**：不相容选言命题，A和B不可同真，也不可同假，有且只有一个是真的。

### （6）有的A是B

**注意**：在逻辑中涵盖三种情况：
1. 1个A是B
2. 部分A是B
3. 所有的A都是B

### （7）不都与都不

- "不都" = "并非所有" = "有的不"
- "都不" = "所有不"

**例题1（2014联考）**

> 老王对老李说："除非你在今天之内按照合同要求支付货款，否则我们法庭上见。"

**解析**：翻译得到：-支付货款→法庭见。B选项犯了否前推否后的错误。

## 五、五对矛盾关系

### 矛盾关系的性质

| 性质 | 说明 |
|------|------|
| **性质一** | 互为矛盾关系的双方主体必须一致 |
| **性质二** | A+非A=全世界，不存在第三种情况 |
| **性质三** | 矛盾关系的双方，必有一真必有一假 |

### 五对矛盾关系

| 序号 | 矛盾对 | 说明 |
|------|--------|------|
| 1 | A与非A | 单论点与单论点的否定 |
| 2 | 所有A都是B 与 有的A不是B | 全称肯定与特称否定 |
| 3 | 所有A都不是B 与 有的A是B | 全称否定与特称肯定 |
| 4 | A且B 与 -A或-B | 联言与选言的否定 |
| 5 | A或B 与 -A且-B | 选言与联言的否定 |

**例题（2015联考）**

> 甲说："犯罪嫌疑人向东逃跑了。"
> 乙说："犯罪嫌疑人没有向东逃跑。"
> 丙说："犯罪嫌疑人没有向南逃跑。"

**解析**：甲和乙的说法是矛盾关系，必有一真一假。

## 六、两大反对关系

### 1. 上反对关系

**关系**：所有A都是B 与 所有A都不是B

**性质**：不能同真，可以同假

### 2. 下反对关系

**关系**：有的A是B 与 有的A不是B

**性质**：可以同真，不能同假

## 七、推出关系

### 全称与特称的推出关系

| 全称命题 | 推出 | 特称命题 |
|----------|------|----------|
| 所有A都是B | → | 有的A是B |
| 所有A都不是B | → | 有的A不是B |

---

## 八、等价关系

### 常见等价关系

| 原命题 | 等价命题 |
|--------|----------|
| A→B | -B→-A（逆否命题） |
| 并非（A且B） | -A或-B |
| 并非（A或B） | -A且-B |
| 有的A是B | 有的B是A |
| 所有A都不是B | 所有B都不是A |

---

## 九、模态命题

### 模态命题的矛盾关系

| 模态命题 | 矛盾命题 |
|----------|----------|
| 必然P | 可能非P |
| 可能P | 必然非P |
| 必然非P | 可能P |
| 可能非P | 必然P |

### 模态命题的推出关系

| 模态 | 推出 |
|------|------|
| 必然P | 可能P |
| 必然非P | 可能非P |

> 💡 **解题技巧**：
> 1. 熟练掌握五个复句翻译（充分、必要、逆否、联言、选言）
> 2. 牢记八个单句翻译的等价关系
> 3. 注意区分矛盾关系和反对关系
> 4. 掌握逆否命题的等价转换
> 5. 遇到"有的"要想到三种情况
